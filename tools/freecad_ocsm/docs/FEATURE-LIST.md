# OCSM Export 功能清单与验收步骤（2026-10-23）

适用版本：`tools/freecad_ocsm`（FreeCAD 1.1.3 / OCCT 7.9.3 实测）。自动化回归已通过；**带 ☐ 的是需要你在真实 GUI/OCS 中手测的项目**。

## A. 安装与入口

| # | 操作 | 期望 |
|---|---|---|
| A1 ☐ | `python3 install.py --mod-dir ~/.local/share/FreeCAD/v1-1/Mod --dry-run` | 只打印将创建的符号链接，不写文件 |
| A2 ☐ | 去掉 `--dry-run` 后重启 FreeCAD | 出现 `OCSM Export` 工作台；已存在同名目录时拒绝覆盖 |
| A3 ☐ | 工作台点“导出选中对象…” | 独立 modeless 窗口，不占用 Control 面板；关闭后模型不变 |
| A4 ☐ | 运行宏 `OCSMExport.FCMacro` | 与 A3 相同窗口；重复运行复用窗口 |
| A5 | Python API `export_objects(objects, path)` | 写 DXF + `name.manifest.json`；无 GUI 依赖 |

## B. 选择与范围

| # | 操作 | 期望 |
|---|---|---|
| B1 ☐ | 不选任何对象直接预览/导出 | 明确报“请选择至少一个对象”，不导出整个文档 |
| B2 ☐ | 选一个 Body（含历史特征） | 只投影最终 Tip，不含被吃掉的 Pad/Pocket 历史 |
| B3 ☐ | 选 `App::Part`/组 | 只含可见子对象；隐藏子对象默认跳过 |
| B4 ☐ | 选 `App::Link` 实例 | 按该实例的 LinkPlacement 与祖先 Placement 定位，不双重变换 |
| B5 ☐ | 同时选 Body 和它内部的一个特征 | 只导出一次（相同几何去重），不出现重复线/重复剖面 |
| B6 ☐ | 选带面/边子元素的 TechDraw 视图（`XSource` 非空） | 明确拒绝并提示“子元素投影未支持”，不静默改为全对象 |
| B7 ☐ | 选两个完全重合的相同零件 | 只导出一次（并集/遮挡结果相同） |
| B8 ☐ | 修改模型后不重新预览直接导出 | 导出仍重新计算，不使用过期快照 |

## C. 视向

| # | 操作 | 期望 |
|---|---|---|
| C1 ☐ | 勾选前/后/左/右/上/下 | 六个正投影方向正确；前视宽高与模型 X/Z 对应 |
| C2 ☐ | 勾选 ISO | 正交轴测，圆变椭圆（ELLIPSE，不是折线） |
| C3 ☐ | 勾选多个视向，选第一角 | 俯视图在主视图正下方、左视图在右侧，中心对齐、20 mm 间隙；每个视图一块，仅平移，1:1 |
| C4 ☐ | 切到第三角 | 俯视图在主视图上方、右视图在右侧；与第一角不混用 |
| C4 ☐ | “当前相机（正交视向）” | 读取当前三维视图方向与上方向；透视相机被拒绝 |
| C5 ☐ | 自定义视向 + 上方向 + 旋转 30° | 图形绕视向逆时针旋转 30°；非法/平行向量明确报错 |
| C6 ☐ | 选一个纸面 1:2 的 TechDraw 视图并“读取视图设置” | 参数继承，但导出仍是模型 1:1（清单记录 ignored paper scale） |

## D. 三种输出模式

| # | 操作 | 期望 |
|---|---|---|
| D1 ☐ | 主视图选纯实线、俯视图选全剖 | 两个视图各自按所选模式输出；剖视只在俯视图产生 `5剖面线层` 填充 |
| D2 ☐ | 同一导出里混合纯实线/隐藏/全剖/全剖+隐藏 | 每个勾选视图的模式互不影响；剖切平面共用 |
| D4 ☐ | 阶梯圆柱主视图 | 水平边为 LINE（不是 SPLINE）；台阶处共线分段合并为一条 |
| D3 ☐ | 平面全剖 | 截面轮廓在 `1轮廓实线层`，填充在 `5剖面线层`，不重复复制轮廓 |
| D4 ☐ | 剖视勾选“剖视也输出隐藏边” | 保留侧被遮挡的边进 `4虚线层` |
| D5 ☐ | 关闭“输出剖面填充” | 只输出截面轮廓，`5剖面线层` 为空（对应 TechDraw `NoCut`） |

## E. 高级参数

| # | 操作 | 期望 |
|---|---|---|
| E1 ☐ | 打开/关闭“可见相切/平滑边”“曲面接缝” | 仅影响对应边，不改变其它轮廓 |
| E2 ☐ | 隐藏硬边/隐藏相切/隐藏接缝三态 | “跟随可见设置/独立开/独立关”分别生效 |
| E3 ☐ | 误差容限 0.01 mm | 正投影已知尺寸偏差 ≤0.01 mm（ISO 按投影长度核对，不比三维原长） |
| E4 ☐ | 含不支持曲线，默认不勾“允许离散” | 明确报错，不写文件 |
| E5 ☐ | 勾“允许离散” | 导出成功并报告具体实体、误差/损失警告 |
| E6 ☐ | 含 CosmeticEdges / CosmeticVertexes / CenterLines / GeomFormats | 默认明确报错；主动取消“包含修饰线”后仅导出模型几何并写警告 |

## F. 剖视

| # | 操作 | 期望 |
|---|---|---|
| F1 ☐ | 手填剖切原点/法向/保留侧 | 只保留指定半空间；从被移除侧观察才能填充 |
| F2 ☐ | 点“取选区中心（只读）” | 原点填为选区包围盒中心，模型不变 |
| F3 ☐ | 剖切面不相交 / 与视向平行 / 从保留侧观察 | 明确报错，不输出空图或错误填充 |
| F4 ☐ | 空心套筒（内孔） | 外环 + 内孔两个 loop；孔内不填充 |
| F5 ☐ | 一个 compound 内“完全保留实体 + 被切实体” | 只填充真正被切的实体；保留实体的共面表面不填充 |
| F6 ☐ | 斜切圆柱（ISO/任意视向） | HATCH 边界是解析椭圆，不是折线 |
| F7 ☐ | 两个不连通截面区域 | 分别填充；同零件同角度，不同来源交替 45°/135° |
| F8 ☐ | 读取 TechDraw 剖视：HatchScale=2、HatchRotation=30、NoCut | 间距 6.35、角度 75°、NoCut 不填充 |
| F9 ☐ | TechDraw 剖视 `TrimAfterCut=True` / `CutSurfaceDisplay=Solid` / `UsePreviousCut` / `FuseBeforeCut` | 分别明确拒绝并说明原因 |
| F10 ☐ | 剖视继承非默认图案（如 ANSI31） | 导出为 `OCSM_SECTION` 并写警告“图案几何不同”；不静默声称一致 |

## G. 预览

| # | 操作 | 期望 |
|---|---|---|
| G1 ☐ | 点“预览（纯 SVG）” | 右侧显示视图；报告采样尺寸（mm）、图层统计、警告 |
| G2 ☐ | 改任意参数 | 预览立即标记为“已过期”，不显示旧图 |
| G3 ☐ | 预览后修改模型几何 | 导出仍重新计算；预览不创建任何 FreeCAD 对象 |
| G4 ☐ | 多视图预览 | 每个视图独立面板，定义 ID 不冲突 |

## H. DXF 输出

| # | 操作 | 期望 |
|---|---|---|
| H1 ☐ | 导出后检查文件 | DXF R2013/AC1027、UTF-8、`$INSUNITS=4`（mm）、模型空间 1:1 |
| H2 ☐ | 检查图层 | 恰好 `1轮廓实线层`(7/Continuous/0.35)、`2细线层`(4/Continuous/0.18)、`3中心线层`(1/CENTER2/0.18)、`4虚线层`(6/DASHED2/0.18)、`5剖面线层`(2/Continuous/0.18) |
| H3 ☐ | 检查任一实体和块内实体 | 颜色/线型/线宽均为 ByLayer（不是硬编码） |
| H4 ☐ | 检查多视图 | 块名 `OCSM_VIEW_xxx`，INSERT 只在 0 层，块内实体在 1—5 层，只有平移 |
| H5 ☐ | 检查剖面 | 原生 HATCH，含内孔/岛；角度/间距与设置一致；不是填充线段 |
| H6 ☐ | 打开同名清单 | 含来源、设置、统计、placements、警告、DXF SHA256 |
| H7 ☐ | 目标已存在 | 弹窗确认后才覆盖；取消则不写 |
| H8 ☐ | 目标是符号链接/目录/不存在目录 | 明确拒绝，不跟随链接写真实文件、不自动建目录 |
| H9 ☐ | 目标被占用/只读 | 明确报错；不返回“导出成功” |
| H10 ☐ | 连续导出两次 | 第二次不覆盖除非确认；清单哈希与 DXF 对应 |

## I. OCS 使用（宿主能力）

| # | 操作 | 期望 |
|---|---|---|
| I1 ☐ | OCS 直接打开导出的 DXF | 几何、图层、线型、线宽正确；中文层名正常 |
| I2 | 作为块/外部参照插入 | **OCS 宿主功能，不计入本工具验收**；DXF 只是普通模型空间/块结构，宿主可自行插入 |
| I3 ☐ | 保存后重开 | HATCH、孔洞、ELLIPSE/SPLINE、ByLayer 不丢失 |
| I4 ☐ | 图形界面查看剖面 | 剖面线方向/间距正确，孔内空白，不实心 |
| I5 ☐ | 与 FreeCAD 预览对照 | 轮廓方向、隐藏线、剖切范围一致 |

## J. 已知限制（测试时不要当故障）

- 自动尺寸/公差、图框/明细表/BOM、双向更新、复杂剖视（阶梯/旋转/局部/半剖）不在本版。
- 中心线/修饰线**不导出**（默认防丢报错）；不自动生成中心线。
- 剖视方向、肋板不剖、螺栓/轴纵剖、螺纹/齿轮简化需人工控制，几何剖切不等于全部制图规范。
- 剖视继承时图案名统一为 `OCSM_SECTION`，`HatchOffset` 不映射（会写警告）。
- 双文件（DXF + manifest）不是掉电级原子提交；异常终止后按清单哈希检查。
- 大装配性能未承诺；完全重合的相同几何会去重为一次。
