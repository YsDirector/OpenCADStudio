几何参数

不勾选 = 普通齿轮（体系下拉 M 模数制 / DP 径节制；给花键标准号或 d_B 会明确报错）； 勾选 = 渐开线花键（GB/DIN/NF/ANSI 四种体系，内/外花键仍用下面的「齿轮种类」开关切换）。 NF 已入库（公称直径 A 主参数，p18/p20/p21/p22 共 288 行）；ANSI 已接入（径节 P + Table 2 五列）。
d_B 只属于 DIN 5480；NF E22-141 用公称直径 A。GB/T 3478 下不给（本体系没有基准直径）。 给 d_B / A 后 m 或 z 可空一个：由表定另一个。
模数制用 m；径节制用 DP（块名/规格保留 DP 原值，避免与同模数件串块）。M 与 DP 只能选一个。
m = 25.4/DP（径节系列下拉暂不做，可输入任意 DP）
