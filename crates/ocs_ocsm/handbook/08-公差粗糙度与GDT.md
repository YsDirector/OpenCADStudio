# 08 公差、配合、粗糙度、GDT 符号

> 尺寸公差、配合代号、表面粗糙度、形位公差/基准/工程符号，都在**标注配置窗口**里做（`OCSMDIMGULIDE` 打开）。

## 一、尺寸公差（`TOLERANCE`）

两种模式（在配置窗口里切）：

| 模式 | 写法 | 适用 |
| --- | --- | --- |
| **代号模式** | `⌀30H7`、`⌀30k6` | 有配合关系的配合尺寸 |
| **极限偏差模式** | `⌀30 +0.021/0`（上下偏差） | 单件尺寸、按工艺给定 |

- **配合表**：插件内置 ISO 286 的 4 张表（孔/轴 × 常用公差带），选代号时自动查偏差；
  常用配合的极限偏差不需要你去翻手册。
- 直径/半径公差：以**匿名块块内 MTEXT 堆叠**形式画出（上下偏差上下叠放），符合国标记法。
- 只给"文字 override"时按你的文字原样输出（保留手写成分）。

## 二、形位公差（`GD&T`）与基准（`DATUM`）

- **形位公差框**：引导 = 1 条 PLINE 定位框位置；内容 = 符号（直线度/圆度/平行度/位置度…）+ 公差值 +
  基准字母，在窗口里选（有 **GDT 符号字体**，不靠打字符拼）。
- **基准符号**：两种国标画法（1996 / 2008），按项目要求选。
- 符号类产出进 `8符号标注层`（匿名块 + INSERT）。

### 一般设计任务：形位公差输入的语义预检（不只适用于抄图）

本节按 **GB/T 1182-2018**（现行，修改采用 ISO 1101:2017）整理，是设计输入预检摘要，不替代标准原文。形位公差不能只检查“符号、数值、基准字母是否填了”；在生成几何和标注前，必须闭合这条链：

```text
被测要素类型 → 公差特征 → 公差带形式 → 基准体系/自由度 → TED/基本尺寸与检验方向
```

链条不闭合或角色冲突时，禁止继续生成，报 `INPUT_CONTRADICTION`，并指出缺少或不兼容的输入。不能因为 OCSM 窗口允许填写基准栏，就把任意基准字母当成合法设计。

#### 1. 特征项目—基准语义速查

| 特征项目 | 基准栏 | 输入预检的工程语义 | 典型否决条件 |
| --- | --- | --- | --- |
| 直线度、平面度、圆度、圆柱度 | 原则上无 | 形状公差的公差带由被测要素自身定义；先确认被测的是表面线、轴线/导出中线、平面、圆截面还是圆柱面 | 把不需要基准的纯形状要求写成依赖 A/B/C；被测要素类型与公差带不匹配。轴线直线度仍可按标准使用 `⌀`、`Ⓜ/Ⓛ` 等适用修饰符，但不因此获得基准。 |
| 线轮廓度、面轮廓度 | 可无、可有 | 无基准时主要控制轮廓自身形状；带基准后，在基准体系约束的自由度内还可控制方向和/或位置；必须有理论轮廓/名义几何 | 带了基准却没有可解释的理论轮廓、基准体系或名义几何；把“带基准”绝对解释成同时锁死全部方向和位置。 |
| 平行度、垂直度 | 必须有 | 方向公差；基准可以是基准平面、轴/中心线、中心平面或相应组合体系，具体按被测要素、公差带和目标方向判定 | 基准不能提供所需方向；例如需要基准轴却只给了不能建立轴线的孤立端面。 |
| 倾斜度 | 必须有 | 方向由基准和理论正确角度确定；角度用 TED/基本角表达，不用普通角度公差替代 | 缺基准、缺理论角，或把 0°/90°关系误写成倾斜度而没有必要的角度语义。 |
| 位置度 | 可无、可有 | 有基准时检查基准顺序、实际所需自由度以及 TED/基本尺寸定义的理论位置；无基准时不能自动解释成相对整件全局坐标系的绝对定位 | 没有理论位置/基本尺寸；基准不足以支持功能或检验，却擅自补 A/B/C；机械要求基准必须锁定全部六个自由度。 |
| 同轴度 | 必须有 | 基准必须提供唯一基准轴线或等效中心线 | 用单独平面/端面代替基准轴；未说明轴线由哪个旋转要素或基准体系导出。 |
| 对称度 | 必须有 | 基准必须能与被测导出中面、中心线或轴线建立规定的对称关系；具体是基准平面、中心平面或基准轴/线，要随被测要素和公差带判定 | 任意平面/轴线被静默当作所需的中心关系；要求中面却只给了不匹配的侧面。 |
| 圆跳动、全跳动 | 必须有 | 必须由圆柱、圆锥等旋转要素，公共/组合基准或其他明确体系建立唯一回转轴；圆跳动按各截面检查，全跳动覆盖整个被测表面 | 把单独的环形端面/平面作为唯一轴基准；未能说明基准轴的来源。 |

“必须有基准”表示该特征项目的标准语义需要基准参考，不表示基准只能是一种物理表面；“可无、可有”也不表示可以省略理论轮廓或理论位置。

#### 2. 基准角色兼容矩阵

| 所需基准角色 | 常见合法来源 | 不能单独替代 |
| --- | --- | --- |
| 回转轴/中心线 | 外圆柱面、内孔圆柱面、圆锥旋转要素、明确的中心要素、公共基准或能导出轴线的组合体系 | 单独一个平面或端面；它只能给出方向，不能唯一给出轴线位置 |
| 基准方向 | 基准平面的法向、基准轴/中心线的方向，或相应组合体系 | 只有一个点而没有方向定义 |
| 基准平面/中心平面 | 实体平面、明确导出的中心/中面、按功能建立的基准体系 | 在要求中心关系时，把任意单侧面冒充中心平面 |
| 定位基准体系 | 按顺序引用的 A\|B\|C（或公共基准）+ TED/基本尺寸；只约束功能和检验真正需要的自由度 | 看到框格空位就自动补基准，或把单一 A 当成万能坐标系 |

因此，本图两处 `圆跳动 | 0.025 | A` 若上游把 A 定义为右端环形端面，必须在建模前否决：端面不能建立唯一回转轴。Φ42 外圆、内孔或其他能产生轴线的要素可以是候选，但仅凭“圆跳动”不能替多个合法候选自动选择设计意图。

#### 3. 修饰符也要做语义预检

- `⌀` 表示相应的圆形/圆柱形公差带，不是可以任意加在数值前的直径装饰。
- `Ⓜ/Ⓛ`（最大实体/最小实体）原则上要求被测要素或基准要素具备标准定义的尺寸特征；写在公差值后与写在基准字母后不是同一语义。
- `Ⓟ`（投影公差带）只适用于标准允许的、具有装配方向和投影长度要求的要素；必须给出投影长度，不能用来弥补缺失的基准或理论位置。
- `Ⓢ`（独立原则）以及其他修饰符不能任意组合；检查时同时看被测要素类型、公差项目、公差带形式和采用的标准版本，不能把 ASME 的默认规则静默混入 GB/T 1182/ISO GPS 口径。

#### 4. 通用设计任务的闭环

1. 将输入规范化为 `target_feature`、被测要素类型、`datum_role`、允许/禁止的基准角色、TED/基本尺寸、检验方向和必要的 `guide_direction`。
2. 按上表检查“公差项目—被测要素—基准体系—修饰符”的兼容性，并检查基准体系实际约束的自由度。
3. 发现冲突就暂停并返回 `INPUT_CONTRADICTION`；缺少功能、装配或测量依据时要求补充，不能凭常见做法选轴或补基准。
4. 通过后才生成几何、引导线和形位公差框；生成后重新回读 `OCSM_EDIT` 的 `p1/p2`、基准连接点和 FCF 参数。
5. 对生成结果再次运行同一语义矩阵，再做结构审计、视觉检查和 `save_verified`。截图不能替代基准自由度和公差带的判定。

这条规则适用于从零设计、改图和抄图；`18-抄图实战口径.md` 中的源图连接语义是额外约束，不是本节通用规则的替代品。

## 三、表面粗糙度（`OCSMRGH`）

```
命令：OCSMRGH
流程：交互点选符号插入点 → 打开「粗糙度配置」窗口 → 选形态 + 填 Ra 值 → 确定
产出：匿名块（含 ATTDEF 文字）+ INSERT（进 8符号标注层）
```

- 形态：基本符号 / 去除材料 / 不去除材料 / 带说明（如 `Ra 3.2`、`Ra 1.6`、`Rz`…）。
- **加工表面默认必须选“去除材料”**（HTTP/API 参数为 `shape:"remove"`）。只有源图明确出现不带横线的基本符号、圆圈“不去除材料”符号或文字说明时，才允许改选其他形态；“通用”不是加工表面的默认替代项。
- 本次抄图中凡是车削、铣削、磨削、钻孔、键槽、齿面等加工表面，均按“去除材料”生成；“其余 Ra12.5”是粗糙度数值的适用范围，不改变局部符号的加工形态。
- 粗糙度**不属于引导线标注类型**（`GuideType` 里没有 `Rgh`，`OCSMDIMGULIDE` 窗口也没有粗糙度页签）；一律走 `OCSMRGH` 独立命令（点选插入点 + 配置窗口）。

## 五、坑

1. **公差依附尺寸**：`TOLERANCE` 是给一条**尺寸标注**加偏差，不是独立符号 → 先有尺寸（宿主原生 `QDIM` 或 `OCSMDIMGULIDE` 引导线尺寸）。
2. **配合代号要选对基准制**：`H7/k6` 是基孔制（常用），`K7/h6` 是基轴制；选错查出来的偏差方向反。
3. **GDT 符号别用手打字**：字体里有专用符号，配置窗口里点选才保证形状正确、不生僻字。
4. **粗糙度值写"Ra"省略**：默认按 `Ra`；写 `Rz` 时要在窗口里改符号类型。
5. **位置、朝向和避让是硬验收项**：粗糙度符号的插入点/尖端必须吸附到目标轮廓线或其合法延长线；符号的朝向必须随吸附线方向旋转，不能只旋转文字或使用默认水平朝向。全局“其余/全部”标注不吸附具体表面，但仍不得遮挡实体或其他标注。
- **旋转选择（默认规则）**：旋转角不是固定 0°。先让 V 形尖端吸附到目标表面/合法延长线，再按目标轮廓的局部方向确定符号相位，并把符号主体和数值放到不压住材料、剖面线或齿廓的可读空白侧（内孔通常放向孔内空白区）。对剖视中的水平表面，通常在 0° 和 180° 之间选：两者保持同一水平基准方向，但把主体换到表面的相反一侧；选择哪一个以避让图面为准。斜线、圆弧和端视图内孔应按局部切线/指向表面的关系调整，不能照搬水平面的角度。
- **整体旋转与文字**：旋转必须施加于整个 INSERT/块（符号、数值和属性布局），不能只转文字。翻转到 90°～270° 方位时，应同步调整 ATTDEF 对齐/局部文字旋转，使最终文字仍向上或向左可读。
- **多视图重复**：同一加工表面在剖视、端视等多个视图重复标注时，重复符号的数值和语义相同；各 INSERT 可因视图净空采用不同 0°/180° 或局部角度，不应把不同朝向误判成不同粗糙度要求。
- **相对端面的外法向规则**：两个相对的平行端面分别标注时，旋转角必须按两端面相反的外法向取相反方向；例如竖直左、右端面可分别用 `+90°`、`-90°`，使 V 形尖端贴在端面、主体朝材料外侧/空白侧，不能把两端面强行使用同一个角度。
- **C2 形态**：V 形内带圆表示“以不去除材料的方法获得”；若 `A/A′` 为空，不应擅自推导或补写数值粗糙度。
6. **符号不得与其他实体和标注视觉干涉**：与非目标轮廓、尺寸线、尺寸文字、形位公差框、中心线和相邻粗糙度符号保持至少 3 mm 净距（按当前模型空间）；不足时沿目标面延长线整体移动符号+引线，或重新选择合法引出方向，不能只把文字压到线里面。
7. 生成后必须截图检查尖端落点、旋转相位、文字可读性和 3 mm 避让；再用 `query`/属性回读 INSERT 的块、图层、属性值和插入点。

#### 视觉避让的可机检验收（交付硬门槛）

“截图看起来没碰”不是通过条件。每次新增、删除或移动粗糙度、尺寸、文字、形位公差或中心线后，必须做一次**语义避让审计**；`save_verified` 的 DXF 结构审计不能替代它。当前 OCS 没有专用避让命令时，必须用 `query`/记录导出的实体数据运行确定性脚本并输出避让表；脚本报错、未知或无法展开块都判 FAIL，不能用肉眼补判。

1. **建立候选集**：读取每个粗糙度 `INSERT` 的块名、插入点、旋转、缩放和属性；将块内可见几何、`ATTDEF/ATTRIB` 文字、引线全部变换到世界坐标。用粗糙度世界包络外扩 3 mm 后做 `query`/空间过滤，取附近轮廓、尺寸、尺寸文字、中心线、公差框和其他符号。不能只拿 INSERT 插入点、V 尖端或屏幕像素作距离依据。
2. **拆分尺寸**：尺寸至少分别计入尺寸线、两条界线/延长线、箭头和尺寸文字；对每个障碍物计算模型空间 XY 最近距离 `min_distance_mm`，保留原始句柄和实体类型。
3. **判定**：
   - 粗糙度尖端与它指定的目标轮廓或合法延长线的接触，是默认允许的 `<3 mm` 接触；
   - 对非目标轮廓、尺寸线/界线/箭头/尺寸文字、GDT 框、中心线和其他符号，`min_distance_mm >= 3.000` 才是 PASS；
   - 其他共享端点必须写明工程语义；不能用“看起来相切/共角”代替记录。每行至少输出：`rough_handle | obstacle_handle/type | min_distance_mm | contact_kind | PASS/FAIL`。任何“约”“大概”或“未展开块”的结果都是 FAIL。
4. **修复优先级**：若粗糙度尖端、旋转和属性均正确，优先移动冲突尺寸的尺寸线偏移；宿主原生尺寸移动**定义点 grip 2**，保持首/次点与端面连接，不得 `MOVE` 整个 DIMENSION，也不得移动延长线原点。`OCSMDIM2GB` 标注按 §四改 `OCSM_EDIT` 导向点并 `apply_refresh`。只有粗糙度本身吸附/朝向错误时才改 INSERT；不能只把文字压到线里面。
5. **闭环**：修复后重新 `query`、重算避让表、`ocs_capture` 截图；全部非目标距离 PASS 后，才允许 `save_verified`。截图是证据，不是几何计算；结构审计和语义避让审计都通过才可交付。

8. **粗糙度窗口也是「钉在图纸上」的**（URL 带 `tab=`）：插入只落在开它那张图；图被关后
   旧窗口立即报错。规则见 `06-引导线标注.md` §五.7。
