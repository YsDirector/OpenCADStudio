# 24 双语文案（中/英）与新增词条

> 用户 2026-09-27 定案：**给 OCSM 做全量英文翻译，使其同时支持中英双语**。
> 本文件是开发侧说明（怎么加词条、怎么切语言、怎么测）；全量字符串规模与分批计划见
> `~/桌面/OCSM/review/i18n_盘点.md`（阶段 1 盘点，2026-09-27）。

## 一、三条不变的口径（用户定的）

1. **卡面文字也要英译**（不只界面）。实现路线：**卡定义只有一份，卡面标签随语言渲染**
   —— **禁止**给每张卡再复制一份英文卡。
2. **标准符号不译**：`D_ei` / `Az` / `Wn` / `Kn` / `d_B` / `m` / `z` / `αD` / `MM` / `IT` … 保持原样。
3. **语言机制**：跟随宿主语言 + 可手动覆盖；所有面向用户的中文文案必须进**单一 catalog**，
   不得散落硬编码字符串（命令关键字/查表键/图层名等**协议记号**除外，见 §六）。

## 二、代码位置与取词 API

* 单一 catalog：`crates/ocs_ocsm/src/i18n.rs`（`CATALOG`，表驱动，**一行一 key：`zh` / `en`**）。
* 取词：
  * `i18n::t("cmd.tf.usage")` —— 按当前语言取词，返回 `String`（按需要可加 `_lang` 变体）；
  * `i18n::t_fmt("cmd.tf.err.unknown_param", &[("arg", tok), ("usage", &usage)])`
    —— `{name}` 占位符插值；**两语的占位符集合必须一致**（`catalog_problems()` 会查）；
  * `i18n::t_lang(i18n::Lang::En, key)` / `t_fmt_lang(...)` —— 显式语言（测试/GUI 预渲染）。
* 语言：
  * `i18n::lang()` / `i18n::set_lang(i18n::Lang::En)` / `i18n::set_lang_auto()`；
  * `i18n::env_lang_source()` 返回当前生效的环境变量与值（排查用）。

### 语言来源（优先级从高到低）

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| 1 | `i18n::set_lang()` | 程序内覆盖：GUI 设置 / 命令开关 / 单测 |
| 2 | 环境变量 `OCSMLANG` | 手动覆盖，如 `OCSMLANG=en`（部署/调试最常用） |
| 3 | 环境变量 `OCSM_LANG` | 兼容别名 |
| 4 | `LC_ALL` → `LC_MESSAGES` → `LANG` | 宿主/system locale 的代理（值认 `zh*` / `en*`，大小写与 `.UTF-8` 后缀不敏感） |
| 5 | 默认 `zh` | 保守默认：既有输出全中文，缺省不改变现行为 |

> 宿主 API（`ocs_plugin_api::host::HostApi`）目前**没有**语言/locale 字段（已逐方法核对），
> 所以阶段 1 用环境变量兜底；**没有改** `ocs_plugin_api/**`。将来宿主暴露语言设置时，
> 只需要改 `resolve_env_lang()` 一处，其余调用点不动。

### 缺 key 的保守默认（绝不返回静默空串）

* key 在 catalog、目标语言串为空 → **回落 `zh`**，并记入 `i18n::missing_keys()`；
* key 完全不在 catalog → 返回 **key 本身**（可见占位，一眼定位），并记入 `missing_keys()`；
* 运行期不 panic；缺失由 `catalog_problems()`（静态）与 `missing_keys()`（运行期）兜住。

## 三、新增一条词条（清单）

1. 在 `i18n.rs` 的 `CATALOG` **对应分节**加一行：`Msg::new("域.对象.用途", "中文", "English")`。
   分节：命令输出 / 报错 / GUI / 卡面标签 / 计算书 / 手册（键名前缀 `cmd.` / `gui.` / `card.` / `report.` / `doc.`）。
2. 把产品路径上的硬编码替换成 `i18n::t(...)` / `i18n::t_fmt(...)`
   —— **只限「推给用户 / 写进图纸 / 进 GUI」的字符串**；命令关键字、查表键、图层名不进 catalog（§六）。
3. 需要插值就写 `{name}` 占位符；**中英两语占位符必须同名齐全**。
4. 卡面/图纸标签：卡定义只一份，标签在渲染时取词；同一句话在 GUI 与 ATTDEF 两处出现时
   **必须共用同一 key**，否则同词两处不一致。
5. 测试：
   * 拿 `global_state_test_lock()`（语言是进程级全局，与 `lib.rs` 的 TF 用例串行）；
   * `set_lang(Zh)` → 断言中文；`set_lang(En)` → 断言英文；结束 `set_lang_auto()`；
   * 竖切样例见 `lib.rs::tests::tf_usage_and_unknown_param_switch_language_via_catalog`
     与 `i18n::tests::*`（完整性 / 回落 / 切换 / 插值 / 环境解析）。
6. 门禁（照仓规）：`cargo test -p ocs_ocsm --lib`（10 连跑）、`cargo build --release -p ocs_ocsm`
   （只编译，别部署到用户主插件目录）、六条 smoke（各自正确 HTML 路径）。

## 四、语言怎么用（用户侧）

* 默认跟随系统 locale；想强制英文（或中文）：

  ```sh
  OCSMLANG=en   # 开 OCS/插件；或写进启动环境
  OCSMLANG=zh   # 强制中文
  ```

* GUI 设置入口（后续批次做）：卡生成器/各窗口读 `i18n` 当前语言，选一次即可全插件生效；
  阶段 1 只提供 `set_lang` 与 `OCSMLANG` 两种方式。

## 六、明确不翻译 / 不改造

| 对象 | 处理 |
| --- | --- |
| `assets/*.csv` 等标准数据 | **不翻**（标准原值/表号；`*_notes.md` 口径说明如需英文化另开单） |
| 命令关键字（`内`/`外`/`公称`/`平`/`圆`…）、查表键 | 不进 catalog；CLI 行为**不随语言变** |
| CAD 图层名/线型名/文字样式名（`1轮廓实线层`、`OCSM_GB`…） | 协议记号，图纸互通性优先，不译 |
| 标准符号、单位、纯数字格式模板（`{} mm`） | 不译/保持原样 |
| 注释、单测断言、`tests/*.mjs` 冒烟文案 | 不计入 catalog；改词条时同步测试 |

## 八、已知坑（踩过的）

* **`spline_gui.html` / `ocsm_gui_common.js` 是 `include_str!` 进 `.so` 的**：
  改页面必须 `cargo build --release` 并只在临时插件目录部署（别碰 `~/.config/OpenCADStudio/plugins/`）。
* **老图不翻译**：卡面标签进了 ATTDEF 就是图纸内容；语言切换只影响**新出表**。
* 语言是进程级全局：单测里切语言必须持 `global_state_test_lock()`，否则与 TF 的报错断言互相打架。
* `catalog_problems()` 只查静态问题；「这个 key 到底有没有人用」要靠运行期 `missing_keys()` + 人查。
