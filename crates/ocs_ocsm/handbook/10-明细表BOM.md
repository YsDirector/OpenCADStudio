# 10 明细表与 BOM（`BOM` / `BOMCFG`）

> 把标准件的 XDATA 汇总成图上的明细表。

## 一、命令

| 命令 | 别名 | 作用 |
| --- | --- | --- |
| `OCSMBOM` | `BOM` | **建表 / 刷新**明细表；可带参数：`BOM 30` = 本次首列先排 **30 行** |
| `OCSMBOMCFG` | `BOMCFG` | **配置**（列/表头/格式等），同样可带行数参数 |

- 数据来源：图纸里标准件 INSERT 的 **XDATA `OCSM_PART`**（族/规格/标准号/材料/重量…）
  → 所以**不要炸开标准件**，也不要手画螺栓外形（那样统计不到）。
- 表体是**行块重复插入**（每行一个块实例），表头在整表最上方；行带 ATTDEF 属性（序号/代号/名称/数量/材料/重量/备注…）。

## 二、位置规则（从图框量出来的，换图框要重对）

以 `a3_landscape.dwg`（A3 横式，185×40 标题栏 + 左侧竖向附加栏）为例：

| 边 | 基准 | A3 横式实测 |
| --- | --- | --- |
| **右边** | 图框**内框右边**（=标题栏右边） | `x = 395` |
| **左边** | 标题栏**左边**（不延伸到左侧附加栏） | `x = 210` |
| **宽** | = 标题栏宽（本图框 **185 mm**，注意不是 200） | 185 |
| **底边** | 标题栏**上沿**，紧贴 | `y = 40`（首行 40→48） |
| **行序** | **自下而上**累积：序号 1 在最下、紧贴标题栏；表头在最上方 | — |
| **高** | 随行数向上生长（首期一行占位高 8 mm） | — |

通用规则：**右边界对齐内框右边；宽度 = 标题栏宽；底边贴标题栏上沿**。

## 三、序号球标（Balloon）

- 明细表三件套 = 表格 + 表头 + **序号球标**（把每个件的序号引到装配图上）。
- 球标与表格的**唯一耦合点 = 序号**：序号在表格里定好，球标指向对应件；改序号要两边同步。

## 四、AI 侧配方

```jsonc
// 1) 先看有哪些标准件（有没有可统计的数据）
{ "op": "read", "op": "query", "parameters": { "type": "Insert" } }
// 2) 建表/刷新（如需要先排 20 行）
{ "op": "execute", "request": { "op": "run", "request_id": "b1", "document_id": 1, "revision": 60, "cmd": "BOM 20" } }
// 3) 配置（表头/列）
{ "op": "execute", "request": { "op": "run", "request_id": "b2", "document_id": 1, "revision": 61, "cmd": "BOMCFG 20" } }
// 4) 核对：表的行块 INSERT + 每行 ATTDEF 值（数量/重量是否合计对）
{ "op": "read", "op": "query", "parameters": { "type": "Insert", "layer": "6文字层" } }
```

## 五、坑

1. **没有标准件就没有内容**：手画的螺栓不会进表（没有 `OCSM_PART` 记录）。
2. **宽度不是 200**：这个图框的标题栏宽 185 —— 按 200 排会超出内框。
3. **行数不够**：`BOM 30` 只是"本次首列先排 30 行"，实际行数由图纸里的件种类数决定；重跑会刷新。
4. **重量**：标准件的重量按体积×钢 7.85 g/cm³ 估算（见 `03`）；非钢材质要自己核。
5. **换图框**：位置基准变（内框右/标题栏宽/标题栏上沿），要重新摆。

## 六、验证清单

- [ ] 表的位置：右边界贴内框右边、底边贴标题栏上沿、宽度 = 标题栏宽。
- [ ] 每行的序号/代号/名称/数量与装配图上的件一致。
- [ ] 表头在整表最上方、序号 1 在最下。
