# 20 知识：国标制图画法（骨架，按需长）

> 这一篇按"遇到哪种图就补哪一段"的方式长。已确认的规矩直接写死；未确认的标 **待核**。

## 一、图线与线型（GB/T 4457.4）

| 图线 | 线型 | 线宽 | 用途 | OCSM 图层 |
| --- | --- | --- | --- | --- |
| 粗实线 | Continuous | 粗（0.5 或 0.7） | 可见轮廓、螺纹牙顶、剖切符号 | `1轮廓实线层` |
| 细实线 | Continuous | 细（≈粗的 1/2） | 尺寸线/界线、剖面线、螺纹牙底、过渡线 | `2细线层` / `7标注层` |
| 细点画线 | CENTER2 | 细 | 轴线、对称线 | `3中心线层` |
| 细虚线 | DASHED2 | 细 | 不可见轮廓 | `4虚线层` |
| 细双点画线 | DIVIDE2 | 细 | 假想投影、可动件极限位置 | `9双点划线层` |
| 波浪线 | Continuous（手绘） | 细 | 断裂边界、局部剖 | `2细线层` |

- 粗:细 = 2:1；同一张图里同类线宽要一致。
- 点画线两端要**超出轮廓 2–5 mm**；圆心处画十字（≤Ø12 时可只画细实线十字）。

## 二、图幅与比例（GB/T 14689）

- 基本幅面：A0 841×1189、A1 594×841、A2 420×594、A3 **297×420**、A4 210×297。
- 留边：装订边 25，其余 5（A4 竖装订边 25 在左）。
- 标题栏：本插件图框 `a3_landscape_att.dwg` 的标题栏 **185×40**（放右下角）+ 左侧附加栏。
- 比例系列：1:1、1:2、1:5、1:10、1:2×10ⁿ…；放大 2:1、5:1…。
  **OCSM 做法**：几何永远 1:1，比例体现在图框缩放；`OCSM_GB_xN` 由 `OCSMDIMGULIDE` / `OCSMDIM2GB` 在实际标注锚点按需创建（见 `02`）。

## 三、螺纹画法（GB/T 4459.1）

- 外螺纹（主视图）：**牙顶用粗实线**（外径）、**牙底用细实线**（小径 ≈0.85d），
  端部倒角 45°（`0.075d`），牙底细线画到倒角处止；杆端倒角用细实线连出。
- 内螺纹（剖视）：牙顶细线、牙底粗线（与外螺纹相反）。
- 旋合部分按**外螺纹**画；不穿通时用虚线表示钻孔深度、细实线表示螺纹终止线。
- OCSM 已按模板逐条核对（`hex_bolt_b_full` / `nut_c41` / `nut_61721` 等），
  **不要手画**，用 `OCSMPART`/`OCSMJOINT`。

## 四、剖视与剖面（GB/T 4458.6 / 17452）

- 剖切符号：粗短画（长 5–10）+ 箭头指示投射方向 + 字母（大写，如 `A—A`）。
- 剖面线：与主要轮廓成 45°，同一零件同向同间距；相邻零件间距/方向要区分（本插件用 ANSI31 两片）。
- **材质区分（GB/T 4457.5）**：金属用 **ANSI31**（45° 单向）；橡胶/非金属用 **ANSI37**（45°+135° 双向网纹）。
  实例：内包骨架有副唇密封圈 FB 型——金属骨架两片 ANSI31、唇口橡胶两片 ANSI37（模板实测）。
- **剖面线四片方向约定**：轴类对称件剖视上外/上内/下外/下内 = 0°/90°/270°/180°（调心滚子轴承 GB/T 288 模板如此）；
  螺母/圆螺母剖视两片 = 0°/270°。
- **实现坑（本库已吸收）**：① `ref_dump` 的 TSV **不填 HATCH 的图层列**（看起来像空层），要看剖面线的层/图案/比例
  必须用 `ezdxf` 读 DXF 的 `HATCH`（`dxf.layer` / `pattern_name` / `pattern_angle` / `pattern_scale` / `paths[].edges`）；
  ② `pattern_scale` 各模板不一（0.25/1.0/1.5 都出现过），线间距 = **3.175 mm × scale**，pattern 定义的 `offset`
  必须同步乘 scale（`partgen_kit::hatch_ansi31_edges` / `hatch_ansi37_edges` 已处理）；
  ③ 剖面线边界**可以含圆弧边**（滚道弧、唇口弧），不能用折线近似（`HatchEdge::Arc` 支持）。
- 常见剖视：全剖、半剖、局部剖、旋转剖、阶梯剖（`SECTION` 引导线支持折线 = 旋转/阶梯剖）。
- 金属零件剖面线细实线，间距 2–4 mm（按图幅调）。

### 四·二、剖面线的角度、比例与颜色（`ocsm_export` 口径，2026-10-30 定案）

三条硬规矩，写死不再手工调：

1. **图案用预制 `ANSI31`，HATCH 角度只能是 `0` 或 `90`。**
   预制图案**自带 45° 斜线**，HATCH 角度只用来把相邻零件转 90° 以示区分（0 → 45° 线，90 → 135° 线）。
   传 45/135 当“斜线角度”会让图案**转两次**（定义角 + `pattern_angle`），出现异常旋转。
   `SectionSpec.hatch_angle_deg` 现在只接受 0/90，其它值**吸附**到最近的 0/90（45→0、135→90），不报错。

2. **比例按分区尺寸自动算，不要全图一个值。**
   公式：`目标间距 = 该剖面分区最窄边 / hatch_min_lines`（默认 6），
   `scale = 目标间距 / hatch_spacing`（默认基准 3.175 mm），限幅 `[hatch_scale_min, hatch_scale_max]`（默认 0.4–2.0）。
   实测：Ø104–Ø142 的端盖落在 `scale 1.02–1.42`，7–10 mm 宽的油封环落在 `0.40–0.52`，每片最窄方向约 6 条线。
   **比例不跟着图案大小走，就会出现“大件稀、小件空”**（端盖曾因 `scale 5` 最窄边只落 1 条线，看起来像没填充）。
   关闭自动：`hatch_auto_scale=False`，此时按 `hatch_spacing` 固定。

3. **颜色必须 ByLayer，不许继承源文件的显式色。**
   `ocsm_export` 输出的 HATCH 已按 `color=256` 写（图层 `5剖面线层` 的颜色决定显示，本项目为 2=黄）。
   ⚠ 但**下游用 ezdxf 再加工时要小心**：`hatch.set_pattern_fill()` 的 `color` 默认值是 **7（白）**，
   二次调用若不显式传 `color=256`，会把颜色写死成白、盖掉图层色。要么别改图案，要么带上 `color=256`。

另外：跨文档搬图元后要随手检查 `color / linetype / lineweight` 是否变成显式值——“看着是白的”往往是属性写死，不是渲染问题。

### 四·一、局部剖：常规/全剖双视图互补裁剪（OCSM / FreeCAD 通用）

> 用户 2026-10-25 结合 `~/桌面/OCSM/局部剖示例.dxf` 的四阶段实例确认。
> 适用于 OCSM 轴生成器输出，也适用于 FreeCAD 三维模型生成/导出的二维视图。

**核心：局部剖不是在常规图上覆盖一层剖面线，而是把常规视图与全剖视图的有效部分互补裁剪后组合。**

#### 准备条件

- 两套视图必须来自**同一零件/模型、相同尺寸参数、相同观察方向与投影法、相同比例和单位**；保留原始副本，在工作副本上裁剪。
- OCSM 轴生成器保持同一完整表达式，分别生成 `VIEW 常规` 与 `VIEW 剖视`；不要为局部剖重新手画整根轴的轮廓。
- FreeCAD 三维转二维时，分别准备对应的常规投影与**真实剖切得到的剖视**。剖切平面/深度须能显露目标局剖的内部结构，不能拿另一观察方向或任意剖深的视图硬拼。

#### 从左到右的四步

| 步骤 | 常规视图 | 全剖视图 / 组合结果 |
| --- | --- | --- |
| 1. 准备两套视图 | 保留未剖的完整外观 | 准备同参数的完整剖视，包含实际剖切轮廓和正确剖面线 |
| 2. 确定同一局剖区域 R | 按源图画局部剖分界曲线 | 将**同一组曲线按对应基准复制**到全剖视图；不能各画一组“看起来相同”的曲线 |
| 3. 互补裁剪 | **删除 R 内**应由剖视替代的图线，保留 R 外未剖部分 | **只保留 R 内**的剖视轮廓、内部结构线与剖面线，去掉 R 外内容 |
| 4. 对齐组合 | 以同一轴线、端面或基准点精确对齐两部分 | 拼成一张局部剖视图；分界线只留一份，清理同一零件内因拼接产生的重合线和重复中心线 |

可记为：**结果 = 常规视图在 R 外的部分 + 全剖视图在 R 内的部分 + 一份分界线。**
R 可以是由自由曲线限定的一片或多片区域，不限于轴向矩形窗口；本例的上下两片只是示例，不要求所有零件都上下对称局剖。

#### 裁剪与验收要点

- **轮廓、内部结构线和 HATCH 边界要一起处理**，不是只裁剖面线。分界线与轮廓精确求交，共用交点；圆/圆弧保留真实曲线，不用折线近似。
- 剖面线必须以裁剪后的**闭合材料区域**为边界；孔、槽等空区不得填充。齿部等按规定不剖的部分，继续沿用原剖视的正确表达。
- 未剖区不得残留剖面线或仅剖后可见的内部线；局剖区不得残留应移除的常规外观线。组合后不得有漏线、断口、同一零件拼接产生的重复轮廓或重复界线。这不要求删除装配图中不同零件块为独立重用而有意保留的重合轮廓；仍须核装配可见性和下游导出，见 `16` §六之一。
- 同一零件各剖片的剖面线方向、间距保持一致；继承原视图的图层与 ByLayer 属性，分界线用 `2细线层`、HATCH 用 `5剖面线层`。
- 用**基准坐标和交点回读 + 局部放大截图 + HATCH 闭合检查**验收，不能只靠屏幕拖动“看着对齐”。交付还须按 `18-抄图实战口径.md` 的要求进行图纸审计和保存往返验证。
- **禁止**用整张全剖替代源图局部剖、用全剖 HATCH 覆盖未剖区，或用涂白遮挡假装完成互补裁剪。

本节记录通用作图流程，**不声称已经提供任意曲线局部剖的一键命令**；具体裁剪命令或自动化接口以当前宿主已核验的能力为准。
实例与源文件说明见 [18-抄图实战口径.md](18-抄图实战口径.md) §九。

## 五、尺寸标注要素（GB/T 4458.4）

- 尺寸界线从轮廓引出，与轮廓留 2–3；尺寸线间距 ≥ 5（小尺寸可外移）。
- 数字：字高 5（OCSM_GB 样式），**字头朝上**；竖直尺寸数字字头朝左。
- 直径 `⌀`、半径 `R`、球 `S`、厚度 `t`、45° 倒角 `C2`；同一图上倒角尽量统一注。
- 文字移到尺寸线外时：尺寸线沿轴延伸（已实现，`DIMTMOVE`）。

## 六、公差与配合（GB/T 1800 系列）

- 优先用**代号**标注（`⌀30H7`）；必要时给极限偏差（`⌀30 +0.021/0`）。
- 基孔制 `H` 常用；与标准件配合的孔优先 `H7`。
- 具体查表：见 `22-知识-公差与配合.md`（插件内置 ISO 286 表）。

## 七、表面粗糙度与形位公差（GB/T 131 / 1182）

- 粗糙度：基本符号 + 数值（`Ra`）；去除材料画小三角；写在轮廓线/尺寸线上，三角形尖端朝表面。
- 粗糙度旋转按“尖端贴面、相位随局部轮廓、正反方向按净空”执行，不固定使用 0°。水平剖视表面通常在 0°/180° 中选一侧；内孔端视图要让符号主体进入孔内空白区；斜线和圆弧按局部切线/指向表面的关系调整。旋转整个 INSERT/块并保持文字正向；同一表面在多个视图重复标注时，朝向可以不同，语义和数值必须一致。相对的平行端面按相反外法向采用相反旋转（竖直左、右端面可用 +90°/-90°），C2 的 V 形内圆表示不去除材料，A/A′ 为空时不补猜数值。
- 形位公差框：格数按需（符号 / 公差值 / 基准）；指引线从框边引出。
- 基准符号：两种国标画法（1996 / 2008），按项目统一。

## 八、装配图与明细表（GB/T 4458.2 / 10609.1）

- 装配图顺序：先画主体 → 再装标准件（`OCSMJOINT`）→ 标注配合/关键尺寸 → 序号球标 → 明细表。
- 序号球标：引线自零件引出、球标在图纸外圈或整齐排列，序号与明细表一一对应。
- 明细表：从下往上填（序号 1 在最下），表头在整表最上方（见 `10`）。
- 螺纹连接剖视里：被连接件剖面线方向相反；螺栓/螺母按不剖画（本插件已按此画法生成）。
