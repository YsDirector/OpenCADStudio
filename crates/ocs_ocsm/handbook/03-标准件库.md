# 03 标准件库（`OCSMPART` / `XL`）

> 插螺栓/螺钉/螺母/垫圈/销，查国标规格。**不要手画标准件**。

## 一、两种用法

| 用法 | 命令 | 适合 |
| --- | --- | --- |
| **人类**：开窗口挑 | `XL`（= `OCSMPART`，**不带参数**） | 边看预览边挑规格、随手放置 |
| **AI/脚本**：一行直插 | `OCSMPART <族> <d> <l> [view 视图] [at x,y] [rot 度]` | 已知规格、批量、可回归 |

不带参数的流程（人类）：

```
OCSMPART            → 打开「OCSM 标准件库」窗口 + 进放置态
窗口里：左树选零件 → 右面选 公称直径 / 长度 / 视图 → 看预览 → 点「零件出库」
回图纸：点一下定位基点 → 移动光标旋转 → 再点落定（可连续，Esc 结束）
```

## 二、语法（AI 直插）

```text
OCSMPART <族> <直径 d> <长度 l> [view <视图>] [at x,y] [rot 度]

例：
OCSMPART hex_bolt_c 10 95 at 150,30 rot 0
OCSMPART nut_c41 8 0 at 150,-30            ← 螺母/垫圈只有 d（l 占位写 0）
OCSMPART washer_971 8 0 view main at 150,-40
```

- **族名**用下表的小写 id（也可用 `族=直径` 形式：见 `04`）。
- `view`：`main` 主视图 / `top` 俯视图 / `end` 左视图 / `section` 剖视（各族支持的视图不同，
  窗口里会列出来；不支持的视图会报错）。
- `at x,y`：基点落点（不给则用图纸里点选的"待放置点"，再不然原点）。
- `rot 度`：绕基点旋转角（`Insert.rotation` 内部是弧度，参数按**度**给）。
- `l`：螺栓/螺钉是要长度；螺母/垫圈/销（部分）忽略或按族含义使用。

> **螺栓 ≠ 螺钉**（用户 2026-09-16 明确）：
> * **螺栓**（kind `bolt`）= 穿过光孔后用螺母拧紧 → 零件库「螺栓」类，`OCSMJOINT` 件链只认这一类；
> * **螺钉**（kind `screw`）= 自带头部、**直接拧入螺纹孔**、不配螺母 → 零件库「螺钉」类
>   （内六角圆柱头螺钉 GB/T 70.1、紧定螺钉 GB/T 77、吊环螺钉 GB/T 825 等）。
> 两者在零件树上是**两个顶级类别**；把螺钉族写进 `OCSMJOINT` 会被拒并提示原因。

> 族清单与规格系列以 `/api/parts`（插件 HTTP）或窗口左树为准；上面的表可能随实现增长。
> `catalog_json` 每个族带 `kind` 字段（bolt/screw/nut/washer/pin/ring/bearing/seal），脚本按它分组比猜族名可靠。

## 四、基点约定（放错位置的 90% 原因）

| 族 | 基点 | 轴向 |
| --- | --- | --- |
| 六角头螺栓/内六角圆柱头螺钉 | **头部支承面 × 轴线** | 杆朝 `+x`（`rot 0` 时杆朝右） |
| 内六角平端紧定螺钉 | **内六角端端面 × 轴线** | 拧入端在 `x=0`，平端朝 `+x` |
| 吊环螺钉 A 型 | **支承面 × 轴线** | 环心在 `+y` 侧、杆沿 `−y`（竖直） |
| 螺母（六角/圆/薄） | **端面 × 轴线** | 螺母占 `x ∈ [0, m]` |
| 垫圈（平/弹/止动） | **端面中心** | 占 `x ∈ [0, 厚]` |
| 挡圈（孔用/轴用） | **端面中心（轴线）** | 挡圈平面 ⊥ `x`，占 `x ∈ [0, s]` |
| 轴承（深沟球/圆锥/调心） | **端面中心 × 轴线** | 剖视：轴线 `y=0`、端面 `x=0` |
| 密封圈 FB 型 | **端面中心 × 轴线** | 剖面：轴线 `x=0`、端面 `y=0` |
| 销 | 端面/中心（见窗口里 `base_hint`） | 沿 `+x` |

> 两参数 GUI 模型：轴承用「内径 d + 宽度 B/T」、密封圈用「轴径 d1 + 外径 D」（同规格多外径的变体在长度下拉里选），
> 详见各族 `len_label`。

所以 `rot -90` = 杆朝下（头在上），`rot 0` = 杆朝右。

## 五、块名与记录

- 插入的块名规则（ASCII，可在块表里认出来）：`OCSM_<族>_<规格>`，例如
  `OCSM_HEX_BOLT_B_FULL_M8_35`、`OCSM_NUT_C41_M8`、`OCSM_WASHER_971_8`。
  规格里的 `×`/`d`/`Ø` 会被转成分隔符（`M8×35 → M8_35`）。
- 每个 INSERT 带 **XDATA `OCSM_PART`**（族的 family/spec/code/规格等）——明细表与"这是标准件"的判据都靠它。
- 插入是**一个撤销条目**（`begin:零件插入` → `commit`）。

## 六、AI 侧配方

```jsonc
// 读族清单与规格（含 kind / sizes / lengths / views）
GET http://127.0.0.1:23751/api/parts
// 预览某规格的 SVG（人工核对用）
GET /api/part_svg?family=hex_bolt_b_full&d=8&l=35&view=main
// 参数化插入（推荐给 AI：确定性、可回归）
{ "op": "execute", "request": { "op": "run", "request_id": "p1", "document_id": 1, "revision": 9,
  "cmd": "OCSMPART hex_bolt_b_full 8 35 at 50,10 rot -90" } }
// 核对：读回 INSERT 与 XDATA
{ "op": "read", "op": "query", "parameters": { "type": "Insert", "detail": "full" } }
```

HTTP 形式（脚本可用）：`POST /api/part_pick`，body = `{"family":"hex_bolt_b_full","d":8,"l":35,"view":"main","x":50,"y":10,"rotation":-90}`。

## 七、坑

1. **`l` 必须落在该族表内系列**：超出范围报错（例如 5783 M8 的 `l` 系列是表内档，
   不是任意值）。要按需求选长度 → 用 `04` 的 `OCSMJOINT`（它自己按供货系列取）。
2. **螺母/垫圈的 `d` 是螺纹规格**（M8 → `d=8`），不是内径/外径；它们的厚度取自国标表。
3. **视图选错**：垫圈"主视图"是**侧视轮廓**（平垫=矩形、弹垫=月牙），装配图里就该用 `main`；
   `end` 是端面圆圈。螺栓主视图 = 轴线水平的侧视。
4. **重复插会建重复块定义吗？** 不会：同名块复用（块名由族+规格决定）。
5. **别把标准件炸开**：炸开后 XDATA 与块名都没了 → 明细表统计不到、`OCSMEDIT` 之类也认不出。
6. **零件库窗口是「钉在图纸上」的**：窗口 URL 带 `tab=<图纸号>`，出库/插入只落在**开它那张图**
   （多张图各开窗口不串图；图被关后旧窗口会立刻报「窗口对应的图纸已关闭」）。规则见
   `06-引导线标注.md` §五.7。
