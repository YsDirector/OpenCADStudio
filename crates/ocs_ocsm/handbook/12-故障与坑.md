# 12 故障与坑（速查）

> 命令没反应、窗口不开、报 revision 错 —— 先在这里找。

## 一、命令层

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 插件命令不在 `op:"commands"` 里 | 插件没加载（或加载的是旧版） | 确认 `~/.config/OpenCADStudio/plugins/opencad.ocsm/` 下的 `.so` 是新构建；重启 OCS |
| 发了命令但报"未知命令" | 命令名拼错 / 该命令没注册前缀 | 用 `op:"commands"` 的清单核对；命令名大小写不敏感，但**别名**要写对（`XL`/`D`/`TF`/`GDIM`/`D2G`/`ME`/`CC`/`BOM`） |
| 命令"没反应" | 正处于某个**交互命令**中，你的输入被当点/参数吃了 | 先 `op:"cancel"`（=Esc），再发命令 |
| 报 `Request payload changed` | 同一个 `request_id` 用了两次（请求体不同） | 每次请求换唯一 `request_id`（如加序号） |
| 报 revision/document 不匹配 | `document_id`/`revision` 过期 | 重新 `read state` 再发 |
| 插件重启后图不见了 | OCS 重启会丢当前文档 | 事先 `save`；或用宿主 `open` 打开文件 |

## 二、窗口层（GUI）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 跑 `OCSM`/`XL`/`OCSMJOINT`/`GDIM` 没开窗口 | 该页面窗口**心跳还在**（页面每 5 s ping 一次，15 s 内有心跳就不重复开） | 关掉旧窗口（或等 15 s）；用 `kdotool search --name "<标题>"` 查、`kdotool windowclose <id>` 关 |
| 窗口开了但内容空白/报"无法装配" | 参数组合在库里查不到（例如族没有该直径） | 看窗口里状态行/报告的错误原文；换成表内有的规格 |
| 窗口里点"确定/装配"没落到图上 | 窗口只是**登记**（建预览块 + 待放置件），真正落图要去图纸里点 | 切回图纸：点基点 → 移动 → 再点落定（Esc 结束） |
| 窗口命令名对了但浏览器打开成标签页 | 系统里已有浏览器会话，`--app` 退化成标签页 | 正常现象；按提示切回图纸 |
| 开发期"改了页面却看到旧内容" | 页面是插件里 `include_str!` 的，需要**重新构建插件**；且旧窗口还活着（心跳） | 重新构建 → 关所有旧窗口 → 再开 |

## 三、几何/标注层

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 标注文字变成图层色、字高不对 | 没跑 `OCSM` 初始化，样式缺失 | 跑 `OCSM`；旧标注用 `D2G` 或重新生成 |
| `GDIM` 报"请先选中一条引导线" | 引导线不在 `10引导线层`，或没选中 | 把线移到 `10引导线层`；先选中再执行 |
| 改完标注参数没变化 | 只点了"应用"（写超链接），没点"应用并刷新" | 再点"应用并刷新" |
| `ME` 报"请先选中一个 OCSM 生成的标注" | 该标注没有 `OCSM_EDIT` 记录（原生标注/标准件） | 先用 `D2G` 转，或对尺寸重新走引导线 |
| 螺栓副里螺母内部有杆线 | `trim off` 关了遮挡裁剪，或件链顺序不对（螺母不在杆上） | 去掉 `trim off`；检查件链顺序（从被连接件往外） |
| 螺栓太长/太短 | 板厚给错 / 件链少了件 / 用了固定长度 `bolt=…:8:40` | 看报告行：`Σ`、`需 l≥`、`取供货长度`、`实际外露`；修件链或 `protrude` |
| 明细表空的 | 图里没有带 `OCSM_PART` 的标准件（手画的） | 用 `XL`/`OCSMJOINT` 插件；不要炸开块 |

## 四、无头/脚本（AI 侧）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `--export` 出不了 png/pdf | 只支持 dwg/dxf | 用其它渲染路径出图（宿主渲染 API / 自绘），或走 GUI 截图 |
| 无头模式下插件命令卡住 | 无头会话**不处理插件 worker 请求**（没有 GUI 事件循环） | 无头只用 `open`/`run <命令+内联坐标>`/`save`；插件命令在 GUI 会话里跑 |
| 截图是黑的/空 | 视口范围不对（对象在别处） | 先 `ZOOM EXTENTS`（或 `ZOOM WINDOW`）；注意交互命令中发 ZOOM 会被吃掉 → 先 cancel |
| 中文乱码 | `$DWGCODEPAGE` / 编码（转 DXF 时常见） | 见 `attdef-conversion` 技能的编码坑；DWG 侧用宿主读写，别手工拼 DXF |

## 五、一条经验

**先看 `history` 日志，再截图。** 插件的所有报告（`OCSMJOINT：…`、`OCSM 初始化完成：…`、
`撤销：…`）都写在命令行日志里；错误原文也在那里。只看"命令返回 ok"会漏掉一半问题。
