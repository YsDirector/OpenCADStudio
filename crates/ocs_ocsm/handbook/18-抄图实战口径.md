# 18 抄图实战口径（比例/图框/标注/标题栏）

> 来源：抄图训练实战（YSD06-260928-a 拨叉 1:1、YSD06-260928-b 连杆 2:1）。
> 本文只写**画图行为口径**（手册该管的部分）；如果遇到的是插件/宿主的 BUG，进
> `~/桌面/AI抄图练习/OCS-修改清单.md`，别写在这里。
>

## 〇、总则：读数只定位，关系才定形（★ 最高优先级，先读这条）

**输入只有纯位图。PDF 的矢量层直接不允许读** —— 不解析 path、不量折线、不三点拟合圆弧。

### 为什么

矢量层/位图都是**投影的离散近似**（实测：一个圆被离散成 49 段折线、一段弧 24 段）。它只记录
「画出来长什么样」，**丢掉了「为什么是这个形状」**。照它逐条落实体 = 把一条闭合轮廓拆成 N 个
互不相干的图元，相邻段各自拟合、端点各自算，于是：

- 相切退化成「大约相切」→ **出现缝**
- 同心/共线退化成「看起来在一条线上」→ 微米级错位累积
- 局部剖的裁剪边界抄的是「图上画到哪」，而不是「分界线在哪、哪一侧被剖掉」

症状就是**大量不闭合的曲线**（摇杆 YSD06-260929-a 那轮的教训）——看起来对、读起来错。

### 分工

| 用途 | 允许的输入 |
| --- | --- |
| **定位** | 位图：零件在图纸上的位置、总体包络、基准在哪、px/mm 标定 |
| **定值** | 位图上的**标注数字**（OCR/识图）—— 尺寸以标注值为真值 |
| **校核** | 位图与重画结果叠合比对 |
| **定形** | ✗ 任何读数；✓ **几何关系**：相切、同心、对称、共线、平行、闭合 |

### 落到操作

- 倒圆角一律 `FILLET`（一条命令完成 求交 + 相切弧 + 修剪两直线），**不手画 ARC**；
  要算就先求偏移线交点当精确圆心（与 FILLET 结果一致）
- 轮廓按**闭合链**定义，最后一个约束负责闭合，而不是 N 段各自到位
- 落完线回读**数值判据**（点线距 = 0.0000、相切偏差 = 0、剖面线间距 = 3.0），不靠肉眼

### 这条为什么比抄图本身重要

**纯设计没有源图可读**。设计的输入是功能要求 + 尺寸 + 标准，形状只能从**约束与意图**推出来。
「关系定形」才是可迁移的技能；源图给的是答案的形状、不是答案的来路，拿它定形 = **背答案**。

## 一、先定图幅与比例（★ 别死守 1:1）

**判据**：
1. 零件包围盒（含标注与文字预留）放进内框后**不能压标题栏**；
2. **观感**：零件若只占图纸一小块（留白过多），就该放大比例 —— 实战里 97×42 的连杆在 A3 上用 1:1 明显过小，改 **2:1** 后才合适。

**OCSM 的语义（务必记牢）**：
```
TF <图框名> <比例> at x,y          # 例：TF a3_landscape_att 2:1 at 0,0
```
- **几何永远 1:1 画**；比例只体现在**图框缩放**和**标注样式**上。
- `2:1`（放大出图）= 图框**缩到一半**；`1:2`（缩小出图）= 图框**放大一倍**。
- 比例 ≠ 1 时插件自动建 `OCSM_GB_xN`（例：2:1 → `OCSM_GB_x0.5`，`dimscale=0.5`）⇒ **打印后字高不变**。
- 标题栏「比例」格要手填（如 `2:1`）。

**换比例的三步（顺序不能反）**：
1. 删旧图框 → `TF <frame> <新比例> at 0,0`；
2. **把零件+中心线整体平移到新内框里的合适位置**（推荐内容居中、避让标题栏）；
3. **让标注跟着走**：见第四节（别用 `MOVE` 直接挪标注）。

> ★ 换比例后**先看 block 定义**：如果这份图以前插过同名图框，请先读第五节"图框块定义"，
> 否则属性会整片继承旧值（字体/对齐/旋转全不对）。

## 二、毂槽（GB/T 1095 轮毂侧键槽）主视图画法

轮毂上的键槽（**毂槽**）在主视图（看孔端面）里的画法，与"随手画两条线"很不一样：

1. **孔要画成"带缺口的圆弧"**：缺口 = 键槽槽口，半角 `φ_tan = atan( (b/2) / y_wall )`，
   其中 `y_wall = √(R² − (b/2)²)`、`R` = 孔半径、`b` = 键宽。
   例：Ø28 孔（R=14）、b=8 ⇒ `y_wall = 13.4164`、槽口在 ±16.586°（**朝键槽方向**）。
   → OCS 里用 `ARC` 三点式画：起点 = 缺口一侧交点、终点 = 另一侧交点、**中点 = 圆弧背面那一点**。
2. **槽壁自孔面起**：从 `(y_wall, ±b/2)` 沿键槽方向画到槽底圆角的切点，**不要画进孔里**。
3. **槽底**：距孔心 `R + t₂`（毂槽深 t₂ 查 GB/T 1095 表 1；实战 Ø28/b=8 若按模板口径取 t₂=4 ⇒ 槽底 x = 18）。
4. **槽底两角 R0.25**（b=8 档，模板 specimen 取 r_max；数据表见插件 `detail.rs` 的 `hub_keyway`）。

★ **踩坑提醒**：如果画"两根直线从孔心一侧贯通到槽底"，量测时很容易把**尺寸界线**与**槽壁**看成一整条
（实战就这么误读过一次）。**画毂槽就别让尺寸界线与槽壁共线**，或干脆只用标注的尺寸界线自动生成。

## 三、半径标注的箭头/引线方向

- 引线沿**半径方向**：`RADIUS` 型引导几何 = **起点圆心、终点圆弧方向**的那条 `LINE`。
- **导引指向哪个象限，文字/箭头就落在哪一侧**。
  美观口径（实战用户口径）：
  * 圆弧大部分在**第二象限** ⇒ 导向指 130° 一类方向，箭头 **Q2 → Q4**（文字在左上）；
  * 圆弧在**第四象限** ⇒ 导向指 −40° 一类方向，箭头 **Q4 → Q2**（文字在右下）。
- 直径标注（Ø）：导向线**穿过圆心**指向文字侧即可；字体/字高由 `OCSM_GB` 统管。

## 四、D2G 之后的标注怎么"动"（★ 不能直接 MOVE）

`D2G`（一键转国标）产出的是 **`DIMENSION` 实体 + 匿名几何块 `*D<n>`（块内几何在世界坐标）**。
⇒ 对标注直接 `MOVE`：**尺寸数据动了、图形没动**（图上看着"标注没移"或"重叠错位"）。

**正解（不删除、不重建）**：

1. 读该标注的记录，找 `application_name = "OCSM_EDIT"` 那条：
   ```
   values = [url, "x1,y1;x2,y2", "line", ""]
   ```
   第二项就是**导向几何**（LINEAR = 两个标注点；DIAMETER/RADIUS = 圆心;圆弧方向点）。
   路径 = `/<Kind>/base/common/extended_data/records/<i>/values/1/String`（Kind = Linear/Aligned/Diameter/Radius）。
2. 用 `op:"set_properties"` 写新的导向点（要改 URL，如加公差 `&up=…&dn=…`、改半径引出长度 `DIM/RADIUS/<dist>`，就同时写 `values/0/String`）。
   —— 记录里的 `extended_data` **可写**（只有 handle/owner 之类身份字段被拦）。
3. `POST http://127.0.0.1:23751/api/apply_refresh {"handle":"0x<H>","url":"<记录里的 url>"}`
   （**必须带 `url`**，缺了报 400）⇒ 插件**删旧建新**，句柄会变，`actual_measurement` 立刻反映新导向。

**"换比例后标注要不要重做"**：2:1 这类换框后，**改用上面 1–3 步重生成**即可（样式随图框自动切到 `OCSM_GB_x0.5`），
不需要重新标一遍。

## 五、图框块定义：换图框前先核对（★ 实战踩过）

- `TF` 插入时，若文档里**已存在同名块定义**（如 `a3_landscape_att`），**会复用它**、不会从 `frame/` 刷新。
- 旧的定义可能是"降级版"（ATTDEF 丢 `style`/`halign`/`valign`/`alignment_point`）⇒ 插入体属性整片继承坏值：
  * `style=Standard` ⇒ 标题栏文字**用错字体**（不是朱雀仿宋）；
  * `halign/valign=0`、`alignment_point=(0,0)` ⇒ 文字落到原点附近（看着"空栏"）、图号横穿图框。
- **判断方法**：读插入体属性 `text_style` 是否 `OCSM_GB`；对照 `~/桌面/OCSM/frame/clean/*.dxf`（模板真值）。
- **处置**：把块定义按模板改回后再 `TF` 插一次（一次即可全部正确）；更彻底是让插件支持"插入时强制重建同名块"。
- ★ 注意**单位**：DXF group 50 是**度**，OCS 记录里是**弧度**（写 `180` 会变成 180 rad ≈ 233°，文字斜着飞出去）。

## 六、标题栏填写（属性 + 长文本压缩）

1. **填值**：`op:"set_properties"`，`collection:"entities"`，`handle` = 图框 INSERT，
   `updates:[{path:"/attributes/<i>/value", value:"…"}]`（下标 `i` 用 `ocs_read op:"records"` 的属性表数出来）。
   常见下标（本机 A3 横版模板）：`6` 左上角图样代号、`7` 材料、`14` 比例、`16` 图样名称、`17` 图样代号。
2. **对齐**：`Middle/Middle` 的文字由 `alignment_point`（格心）定位；换比例后若发现文字跑偏，
   顺手把 `alignment_point` 也按比例设回格心。
3. **长文本压缩**：图号超过 10 个字符会超出格子 ⇒ 设该属性的 **`width_factor`**（实体级优先于样式级的 0.7）：
   `wf = min(1, 0.9 × 格宽 / 估算文字宽)`。实战：14 字符、`h=3.5`、格宽 30mm 时取 `0.75`（≈27mm）刚好不越格。
4. 模板里没有的字段（如「数量」「张次」）**不要自己造**：写进交付说明的"未解项"。

## 七、宿生标注落图层 / D2G 前的小动作

- 宿主原生标注（`DIMLINEAR`/`DIMALIGNED`/`DIMDIAMETER`/`DIMRADIUS`）**落在"当前图层"**，
  不是 `7标注层` ⇒ 建尺寸前先把当前层切到 `7标注层`（发数字键 `7`）。
  （`D`/`GDIM` 这类 OCSM 命令自己会落对层。）
- 建完一批尺寸后跑 `D2G` 统一转国标；命令报告在 `history` 里（"扫描 N 个，转换 M 个"）。
- 一次量测要用**OCS 回读的实测值**：`ocs_read op:"query" parameters:{type:"Dimension",detail:"full"}` →
  `properties.<Linear|Aligned|Diameter|Radius>.base.actual_measurement`。
  ★ 不要用 ezdxf 的 `get_measurement()` 判 D2G 后的对齐/直径标注（会算错，例如把 5.0000 报成 0.8333）。

## 八、自动化小抄（MCP 驱动时）

- **作图命令尽量用 inline 参数一次跑完**：`LINE x1,y1 x2,y2`、`CIRCLE cx,cy,r`、`ARC p1 p2 p3`、
  `DIMLINEAR p1 p2 pdim`、`DIMALIGNED …`、`DIMDIAMETER <十六进制句柄> textpoint`、`DIMRADIUS <handle> textpoint`
  —— 命令跑完会停在下一提示，由宿主自动收尾（日志里见"命令已取消"），实体已落图。
- `op:"batch"` 的形状：`request_id` 必须在**顶层**，**steps 里不要再给 request_id**（否则报
  `batch step 0 must omit request_id`）；`request_id` 必须跨进程唯一（否则 `Request payload changed`）。
- **`select` + `ERASE`**：选区设好后 `run "ERASE"` 即可删；但这两步之间**不要发 `cancel`**（Esc 会清选区）。
- 会话/文档会变：`ocs_sessions` 拿 `session_id` 与 `documents[].id`，**按路径锁定**目标文档再动手。
- 位图源图的读数：先按"一条已知标注"定 `px/mm`，再反算其它尺寸（全部落 ±0.1mm 才算标定对）；
  圆用"圆周暗像素覆盖率最大化"拟合圆心半径，比找极值点稳。

## 附：AI 抄图八条"几何关系"铁律（2026-10-01 摇杆 YSD06-260929-a 全程踩出来的）

1. ★★ **几何必须来自精确约束，不能照读数定形**（详见 §〇 总则）：读数只能"定位"，不能"定形"；
   **PDF 矢量层禁止读**；落线后回读**数值判据**（点线距 = 0.0000、剖面线间距 = 3.0、半径 = 标注值 ✓），不靠肉眼 ✗。
2. ★★ **标注界线原点有两类**：① 特征顶点 ② **中心线/轮廓线的延长线上**（同一尺寸方向优先与相关线**共线** ✓，0.001mm 也算错 ✗）。
3. ★★ **锚在延长线上 ⇒ 必须补延长线，落 `7标注层`** ✓；判定可自动化：最近线段 + 垂距≈0 + 段参数 t 在段外 ✓。
4. ★★ **ALIGNED 标注两端 = 被标注的两个"几何点"本身**（圆心/交点 ✓），不是"尺寸界线看起来该在的位置" ✗；
   尺寸线偏移只由**第三个拾取点**决定 ✓。
5. ★★ **`DIMLINEAR` 两端点不在同一竖/水平线上时，必须显式取「水平/垂直」子选项**（否则按斜向量 ✗）。
6. ★ **倒圆角一律用 `FILLET`**（一条命令完成 求交 + 相切弧 + 修剪两直线 ✓）；不要手画 ARC ✗。
   兜底算法：两条偏移线求交 = 精确圆心（与 FILLET 结果一致 ✓）。
7. ★ **局部剖的可见性由分界线裁定**：被剖掉一侧的曲线**裁剪**（圆→弧 ✓）、可见的直线**延伸到分界线** ✓。
8. ★ **剖面线**：边界必须"真闭合 + 在可见层" ✓；**同一片连通材料只做一个 HATCH**（跨分界会相位错位 ✗）；
   间距由 `pattern.lines[].offset` 决定 ✗（只改 `pattern_scale` 不生效 ✗）。

**判值口径（贯穿全程）**：看 **D2G 显示块 `*D<n>` 内的 TEXT**（图纸真值 ✓）；
✗ 不要用 `ezdxf.get_measurement()`（对 ALIGNED 不可信：真值 5→4.9320、12→3.1058、28→7.2469 ✗）。

## 附二：八条新铁律（2026-10-04 ~ 10-05 支架 YSD06-261004-a 全程踩出来的）

### 铁律 0（★★★ 最高优先级）**画图前先保存落盘（否则进度没有 `.bak` 兜底）**

**用户原话**：「画图前要先保存落盘。因为落盘后 OCS 会定期自动生成`.bak`备份文件，这样即使 OCS 闪退或系统死机，都能自动保存部分进度，重启后还能回档一部分已经画好的内容。否则 `.bak` 会自动落盘在 `/tmp` 中，重启就没了。」

- **开工第一步**：新建 / 打开文档后，**先把文档保存到一个真实工程路径**（例：`产物/<任务号>.dwg`），再开始画。
- 未落盘的文档 ⇒ 自动备份（`.bak`）落在 **`/tmp`** ⇒ 重启清空、进度全丢 ✗；
  已落盘 ⇒ `.bak` 与图纸**同目录**，闪退 / 死机后可以**回档到最近一次自动备份**的进度 ✓。
- 中途至少每个**大特征完成**后存一次（本文主图特征多，建议每完成一个视图/断面就存）。
- 附带好处：`save_verified` 返回的 **audit manifest**（`by_layer` / `by_type` / `total` + `errors:0 warnings:0 dropped_on_save:0`）本身就是**交付证据** ✓。
- 实证：本机历史任务的 `.bak` 就在产物目录里（如 `YSD06-260929-a.bak` 1.0MB），机制确实存在 ✓。

### 铁律 9（★★ 最高优先级）**起止坐标一律由「尺寸链」算，不做像素级定位**

**用户原话**：「我能给你的这些图，都是不需要像素级求坐标的，直接看源图标注上的尺寸链就能把起止坐标算出来。这个最关键，贯穿整张图纸的所有特征。」

做法：先把基准 / 主轴线定下来（如枢轴轴心 `(105,195)`），再沿尺寸链加减推出每个特征的起点、终点：

```
立板右面 X = 105 + 60 = 165      立板左面 X = 165 − 16 = 149
盖板右面 X = 149 + 24 = 173      腹板落点 X = 165 + 4  = 169
基准 A  Y = 195 − 80 = 115       盖板上表面 Y = 115 + 10 = 125
筋板起点 X = 105 − 7  = 98        筋板落点 Y = 75 + 5   = 80
```

- 像素量测只做两件事：① 读不清 / 源图未注的值（辅助）；② **校核**（回读实测值对标注）。
  ✗ 不要用像素反推坐标，更不要用像素去**猜角度**。
- 「起点 + 相切」这类约束一旦凑齐，**图形就唯一确定，根本不需要知道角度**：本轮腹板两条平行棱线 =「过 `(105+60+4, 195−80+10) = (169,125)`、与 Ø35 相切」——角度是派生量 ✓。
  - 坑：从外点向圆作切线有**两条**（本轮 −36.9° 与 −58.2°），选错整条棱线就跑偏 ✗。源图只用来**选分支**，不用来定形 ✓。
- 大件也照此办理：先列「基准 → 尺寸链 → 各特征起止点」推导表，再落图。

### 铁律 10（★★ 贯穿全图）**先读技术要求，未注圆角 / 未注倒角都藏在那里**

**用户原话**：「没看技术要求，那些没标出来的未注圆角、未注倒角，往往藏在技术要求里。这个也是贯穿整张图纸的。」

- 读图第一步：把标题栏 + **技术要求 / 其余 / 未注** 逐条抄下来（本轮即「**未注铸造圆角 R2~R3**」）。这些是**全局口径**，对每个视图每个特征都生效 ✓。
- 落图顺序铁律：**先画带棱边的实形 → 再倒圆角**（`FILLET`，见附一铁律 6）。✗ 不要直接拿一段圆弧当端头糊过去。
- 例外要反过来记：**不是所有尖角都倒圆角**——本轮移出断面**断口处**就明确「断口内无圆角」（那里是断口，不是铸件轮廓 ✓）。

### 铁律 11（★ 移出断面专用）**标线相位 + 长度怎么定**

- **标线 ⊥ 被切断的主体，必须精确 90°**（不是「看起来差不多」）：主体方向由铁律 9 的尺寸链算出，标线取其法向。
- **标线要延长到明显穿过相关轮廓线**（本例穿过主视图筋板棱线），只「碰到」不算 ✓。
- **断面形状从「别的视图」上找对应**：本轮 T 形断面 —— T 横长度 **40** = B-B 视图里**间距较宽**的那对竖线；T 横厚度 **6** = **主视图里那两条平行斜线**的距离；T 竖宽度 **8** = B-B 视图里**间距较窄**的那对竖线。标注值 ↔ 视图特征一一对应 ✓。
- **T 竖上的缺口 = 长度可变**：表示「标线沿主体方向移动时，一定范围内这个 T 都成立，只是 T 竖的长度不一样」，所以那里画**断口（两处波浪线，落 `2细线层`）**，不画实形端面 ✓。
- **中心线相位与长度（CENTER2）**：线型单元 = `[19.05, −3.175, 3.175, −3.175]`，**周期 28.575**。
  **长度取 `n×28.575 − 3.175`** 即可让**首尾都落在长画段上**（本轮取 n=3 → **82.550**）。
  ✗ 随手给长度 ⇒ 端点断在半画上（用户一眼看出「相位不正确」）。
  同理：B-B 两孔轴线、枢轴竖轴线等所有中心线都按这个公式定长度 ✓。

### 铁律 12（★ 局部剖专用）**界线 = 样条曲线，且与圆弧相交；整圆先被横线裁开**

（2026-10-05 支架 YSD06-261004-a 主视图左端凸台，用户当场更正）

- **不是波浪折线、也不是圆弧**：局部剖的界线是**样条曲线（`SPLINE`）**，末端应当**落在（相交于）被切件的圆弧上**；
  典型形态：界线从横线（剖切边界）的末端起笔，下笔成 S 形。
- **整圆先被裁开再当圆弧用**：被两条横线切过的整圆要**裁成圆弧**，只留可见的长弧。
  例：Ø35 圆 `c=(105,195) R=17.5` 被 Y=207 与 Y=186 两条横线裁掉靠左那段（约 22.7mm）⇒ 保留 **210.9°→136.7°** 长弧（弧长 87.29）。
  **自检判据**：圆弧 `bounds.min.x` 应该等于裁剪点 x（本例 89.98），而不是圆的左极值（如 87.5）。
- **剖面线要跟着新界线重画**（旧界线下的 HATCH 边界不适用）。
- **工具口径（OCS 实测）**：
  - `entities_create` **不支持 `Spline`**（只支持 Line/Circle/Arc/LwPolyline/Point/Text/MText/Insert/Solid/Hatch）；样条必须走交互命令：
    `op:"start" cmd:"SPLINE"` → 提示“指定第一点” → 逐点 `input kind:"point"` → `input kind:"enter"` 结束（degree 3 拟合点样条）。
  - 样条会落在**插件自己记的层**（**不是文档当前层**！实测 `clayer` 写-读-回读三重确认为 `2细线层` 时，样条仍落 `5剖面线层` ✗ = 上次 HATCH 用的层）⇒ 事后必须改层；
  - **改图层用 `/common/layer`**，写 `/layer` 会报 `property does not exist` ✗。

### 铁律 13（★ 中心线专用）**缺的中心线用 OCSM 的 `ZX` 补；半条先删再画**

（2026-10-05 支架 YSD06-261004-a，用户口述）

- **用户口径**：「用 OCSM 里的中心线绘制功能，补充所选区域缺失的中心线；**如果已经画了其中一半，则先移除旧的，再画新的**。」
- `ZX`（= `OCSMCENTERLINE`）：
  | 拾取 | 产出 |
  |---|---|
  | 1 个圆 / 圆弧 | **十字**（横 + 竖，一次落图、一次撤销） |
  | 2 根直线（先点的为基准） | **角平分线 / 中线** |

  线长 = **直径（或第一根的投影长）+ n×6**（1:1 → 每端超出 3mm）；中线的位置/长度由**第一根拾取的线**决定 ⇒ 点反了要撤销重来。
- **工具坑（实测）**：
  - `ZX` **不吃 `op:"select"` 做的选区**（仍进点选模式）⇒ 用 `op:"input"` + `kind:"entity"` + **handle + 落在实体上的点**拾取；两根直线的模式要在**第二次提示**时再喂第二根。
  - 产物落**插件自己记的层**，不是手册写的 `3中心线层`、**也不是文档 `clayer`**（实测：`clayer` 已确认为 `2细线层` 时，7 条产物仍落 `5剖面线层` = 上次 HATCH 用的层 ✗）⇒ 画完核层并逐条 `set_properties /common/layer`。
    已定级为 BUG：见 `~/桌面/AI抄图练习/OCS-问题清单.md` **D1**（`SPLINE` 同样中招）；相关 **D2**：`ZX` 不吃 `op:"select"` 选区。
- **补完要核“跨度”**：中心线应**贯通它所定位的各个特征**。例：枢轴十字的横线要一直通到凸台左外侧 3mm（凸台左面 67 ⇒ 到 64），否则凸台那一段会是空白 ✗。

### 铁律 14（★ 孔类结构读图 + 孔生成器）**「上大下小 + 中间两条横线」= 阶梯孔，不是开缝**

（2026-10-05 支架 YSD06-261004-a 凸台孔，用户当场纠正）

- **读图口径**：同一轴线上出现**上面大、下面小**的两段孔，中间夹两条贴得很近的横线 —— 那是**台阶面**，按 **「上段光孔 + 下段螺纹孔」** 读，✗ 不要按「开缝/slot」读（本轮就是这么错的：把 Ø11+M10 的阶梯孔读成了单一螺纹孔）。
- **标注会分开给**：本例上段标注 **Ø11**、下段标注 **M10-7H**，两条各自只说自己那一段（看到两个对不上的标注时先想“是不是两个段”）。
- **端视图必有两套圆**：主视图里“横向缺口把孔分成上下两段”时，A 向/端视图**从上往下看两段都可见** ⇒ 要画：上段整圆（粗） + 下段螺纹的 **3/4 细圆弧（大径）** + 下段底孔整圆（粗）。✗ 只画一套圆就是漏画。
- **剖面线分段画**：上段画到上段孔壁、下段画到下段底孔壁（两段孔壁位置不同，边界要分别取）。
- **孔生成器**：一律用 `OCSMHOLE`（短命令 `DK`）生成，✗ 不要手画孔的底孔/螺纹线。关键参数：
  - 一行直插：`OCSMHOLE 螺纹孔 M10 H7.5 贯通 全长 view 侧视图 at 80,193.5`；
  - ★ **通孔必须同时给 `贯通` 和 `全长`**：只给 `贯通` 时螺纹有效长度仍按自动值 `1.5×d` 生成，会多出一条螺纹终止线（本例踩过）；
  - `view 俯视图` **自带一副十字中心线**，视图已有中心线时会重复 ⇒ 删一副；
  - 产出**不带尺寸标注**（M10-7H 这类另走 GDIM LEADER 补）；
  - 几何：底孔径取 GB/T 6135.3 麻花钻表（M10×1.5 → Ø8.5，非理论小径 8.376）；大径 D1 = d；贯通无 118° 底锥；轴线两端各伸 3mm；
  - ✅ 产出**落层正确**（底孔/终止线→`1轮廓实线层`，大径细线→`2细线层`，轴线→`3中心线层`）—— 与 `ZX`/`SPLINE` 落错层（问题清单 D1）不同。

### 铁律 15（★ 面线口径）**孔口 / 沉台口不打断所在面的轮廓线（通线保留）**

（2026-10-05 支架 YSD06-261004-a 立板左面，用户当场纠正）

- **用户原话**：「沉台画得没问题，但左边是一根通线。一般情况下，**画孔不会破坏这根通线**，就像另一侧那样，通线都是保留的。」
- 口径：在某个面上开孔/开沉台（Ø15 通孔、Ø28 沉台都算）时，**该面的轮廓线仍是一根连续线**（一个 `LINE` 实体，落 `1轮廓实线层`），✗ 不要因为孔口而拆成两段。
- **例外（真实间断才断）**：本例凸台左面在 Y 195.2…198.3 有 **~3mm 的真实间断**（逐像素实测两段 ✓，那是退刀槽/沟槽类结构）—— 那种确实要画两段。
- **判别法（可脚本化）**：拿源图在**该面所在列/行**上做逐像素扫描，看暗像素是**一段还是两段**：
  - 一段 ⇒ 图上必须是一个通线实体；
  - 两段、且间隔≈某特征尺寸 ⇒ 保留断开（并在交接里注明那个尺寸是什么）。
- 修图实操：若某面因孔口被拆成两段 ⇒ 删掉两段、建一条通线；随后回读核验（只应剩一个实体）。

### 铁律 16（★ 2026-10-08）**FILLET 拾取侧决定圆弧分支；不修剪时用 EXTEND 补回**

- 同样的两条直线和同一半径，FILLET 的拾取点所在侧会得到不同圆弧分支；必须按源图选择拾取侧，不能只凭半径判断。本图第二处 R3：斜线取远端、水平线取左侧，得到正确的**左开口**圆弧；水平线取右侧则得到错误的右开口分支。
- OCS 已支持“不修剪”模式（`trim=false`）：命令里先输 `N`（或 Python `M.fillet(..., radius=2, trim=False)`），只加圆弧、两条源直线原样保留、句柄不变，不再需要 FILLET + EXTEND 补回。
  限制：**仅两条独立直线**（`FILLET` 的 `P` 多段线选项仍会修剪）；线+弧/弧+弧等组合会明确报错，不会静默退回修剪。老插件版本没有 `N` 时，仍按「FILLET → 对被剪端 EXTEND」处理。
- 这不是手画 ARC 的替代方案：正确顺序是「实形直线 → FILLET（必要时不修剪）」，圆角仍由 FILLET 生成。

### 铁律 17（★ 2026-10-08）**向视图方向标记与视图标题是两个实体**

- 源图的 A 向视图同时有：主视图处的方向箭头/字母标记，以及 A 向视图正上方独立的水平标题 `A`。
- `/DIM/VIEW/0?let=A` 只负责方向标记；视图标题用 `title=`（别名 `vt=`）让插件**另建一个独立 MText**：`/DIM/VIEW/0?let=A&title=A 向视图&mx=12&my=34`。
  它按图幅比例取字高（h=5×scale）、`rot=0`、`MiddleCenter`、图层 `8符号标注层`，初始锚在标记点 `mx,my`（缺省 0,0）——生成后可以单独移动它；`apply_refresh` 会按 URL 重建，移动位置不保留。
- GUI 的「视图标题」输入框就是该参数；老插件版本没有 `title=` 时，手工另建 MText（本图实测 `h=5`、`rot=0`、`MiddleCenter`、图层 `8符号标注层`），不能把箭头旁的 A 当作视图标题。
