# 16 齿轮（`OCSMGEAR`）—— 外齿轮 + 内齿轮齿圈

> **前置要求**：先跑过 `OCSM` 初始化（建 10 图层 + 线型 + 文字/标注样式）。
> 没初始化的图纸执行 `OCSMGEAR` 会**直接拦下来并报缺什么**（用户 2026-09-17 定案）；
> 不然切出来的图“中心线是实线白线、剖面线层颜色也不对”。
>
> 参数化画**圆柱齿轮**（直齿 / 斜齿、可带变位），一次出一个视图，四个视图任选：
> **剖视图 / 侧视图 / 简化正视图 / 常规正视图**。
> 放置方式与 `XL`（标准件）**完全一样**：窗口里「生成到图纸」→ 回图纸点基点 →
> 移动光标旋转 → 再点落定（可连续，Esc 结束）。
>
> **一期只画外齿轮**；内齿轮二期（等外齿轮验收后做）。
> 画法唯一权威 = 用户模板 `~/桌面/OCSM/齿轮/齿轮画法.dxf`（m=2 z=40 h=20），
> 本命令的每个构造规则都是从那张图反解并逐点核对出来的。

## 一、两种用法

| 用法 | 命令 | 结果 |
| --- | --- | --- |
| 人用（推荐） | `OCSMGEAR` | 打开**齿轮窗口**：左上预览 + 4 个视图按钮 + 参数表单；点「生成到图纸」后鼠标带图，点击放置 |
| AI / 脚本 | `OCSMGEAR [内齿轮\|int] <m> <z> [h] [键=值…] [view 视图] [at x,y] [rot 度]` | 直接生成并插入（`at` 给了就落在该点，否则落在待放置点/原点） |

参数键（命令行与窗口同一套）：

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `int` / `内齿轮`（位置参数，或 `kind=internal`） | **切成内齿轮（齿圈）** —— 见第四节 | 外齿轮 |
| `m`（第 1 个位置参数） | 法向模数 Mn（斜齿轮就是 Mn） | — |
| `z`（第 2 个） | 齿数 | — |
| `h`（第 3 个 / `h=`） | 厚度（齿宽） | 外齿轮 `10×m`；内齿轮 `15×m` |
| `ha=` | 齿顶高系数 ha* | `1` |
| `c=` | 顶隙系数 c* | `0.25` |
| `alpha=`（也认 `α25` 紧凑写法） | **基准齿形角 α**（度；默认 20°，合理区间 **10°<α<50°**，常用 14.5/15/17.5/20/22.5/25/30/37.5/45） | `20` |
| `beta=` | 螺旋角 β（**度**，右旋为正、左旋为负；0 = 直齿） | `0` |
| `x=` | 变位系数 Xn | `0` |
| `view` | `剖视图`/`section`、`侧视图`/`side`、`简化正视图`/`simplified`、`常规正视图`/`front`（内齿轮还认 `端视图`） | `剖视图` |
| `at x,y` | 插入点 | 待放置点或原点 |
| `rot 度` | 旋转角（逆时针，度） | `0` |

例：

```
OCSMGEAR 2 40 20                                  ← 剖视图（默认），落在待放置点
OCSMGEAR 2 40 20 view 常规正视图 at 300,200        ← 常规正视图，落在 (300,200)
OCSMGEAR m=3 z=25 h=30 beta=-8 x=0.2 view 侧视图
OCSMGEAR 2 40 20 alpha 25 view 剖视图              ← 压力角 25°（也可写 α25）
OCSMGEAR int 2 40 30 alpha 25 view 剖视图        ← 内齿轮（齿圈），厚度 30、压力角 25°
OCSMGEAR int 2 40 30 view 端视图 at 300,200
OCSMGEAR m=2 z=40 h=20 alpha 45 ha=0.5 view 端视图  ← 45° 必须配短齿顶（ha*<1，否则齿顶变尖）
```

## 二、四个视图分别是什么

| 视图 | 内容 | 什么时候用 |
| --- | --- | --- |
| **剖视图** | 齿顶圆柱（带轴向倒角）+ **齿根线** + 分度线（点划线）+ 轴线 + **剖面线**（ANSI31，轴线上下一共两个环：齿根圆↔轴线） | 装配图/零件图主视图，最常用 |
| **侧视图** | 同上但**不剖**：无齿根线、无剖面线；斜齿轮多**三条细实线**表示轮齿倾斜方向 | 与剖视图配对；斜齿轮必看 |
| **简化正视图** | 齿顶圆（粗实线）+ 分度圆（点划线）+ 齿根圆（细实线）+ 十字中心线 | 快速表达、装配图 |
| **常规正视图** | 真实**渐开线**齿廓（每齿 8 个实体）+ 分度圆 + 十字中心线 | 需要真齿形时（线切割、检验） |

## 三、画法要点（都从模板反解，不是手册臆造）

* **齿廓**：渐开线（**默认 α=20°，`alpha=` 可调**；14.5°/25°/30°/37.5°/45° 都支持），用 **clamped 3 次 B 样条**表示，每条齿廓 **7 个控制点**
  —— 拟合点取在 `r = 有效起点 + (ra−有效起点)·{1/8, ¼, ½, ¾, 1}`（5 点），节点按**弦长参数化**。
  有效起点通常 = 基圆半径 `rb`；当基圆落到齿根圆以内（`rb < rf`，如 z=40 时 α>20.36°）时，
  渐开线在根圆以内没有材料意义，拟合带改从**齿根圆**起算（默认 20° 时 `rb=37.588 > rf=37.5`，行为与加 α 参数前逐点一致）。
  模板实测：全 80 条样条对理论渐开线最大偏差 0.012°（≈9 µm），本实现 ≈5 µm。
* **精度是硬约束**：这套"每齿 8 实体 / 齿廓 7 控制点"是用户验证过的**兼顾加工与性能**的最佳平衡，
  **不要提高精度**（试过更高精度，电脑带不动）。
* **齿根过渡圆角**：ρ = **0.38m**（GB/T 1356）。**大齿数（模板口径）**：圆心在 `r = rf+ρ` 上，并且**到齿廓起点的距离 = ρ**
  （只与齿根圆相切，与齿廓“搭上”）。
* **小齿数降级**（用户 2026-09-17 报 z=17 渲染异常后定案）：上面那条构造等价于三角形
  `r_c = rf+ρ`、`r_s = 齿廓起点半径`、`ρ`——**可解条件 = |r_c − r_s| ≤ ρ**。齿数小时 `r_s` 比 `r_c` 高出超过 ρ，就无解了。
  无解时**不出乱图**，而是给警告 + 两级降级（都写进命令提示与 GUI 提示）：
  1. **降级①（FreeCAD `fcgear/involute.py` 口径）**：渐开线只到**基圆**，基圆以下用**指向圆心的直线**
     接到圆角弧顶（圆角保留）。弧顶同一半径线上，圆心角 `δ = 2·asin(ρ/(2·Rci))`。
  2. **降级②**：连圆角都放不下 → **圆角 = 0**（直线直接落到齿根圆）。

  > 边界（m=10）：z≥20 走模板口径；z≈17↔19 是临界区；z=17/14/7 走降级①。
  > 降级段少了真实根切曲线的凹形（真实齿根 = 刀尖圆角中心次摆线的等距线，需要刀具相位标定）——
  > 渲染不会出错，但与实际滚齿形状略有差异；要真实根切曲线请用变位（`x=`）或另给画法模板。
* **轴向倒角**：`C = round(0.6m)`（用户定案），45°，落在**齿顶圆柱两端**；
  齿顶面长度 = `h − 2C`，端面线画到 `±(da/2 − C)`。
  * 侧视图有两条**倒角台阶线**（`x = ±(h/2 − C)`）；
  * **剖视图没有这两条**（模板就是这么画的，全剖时该棱边省略）。
* **分度圆 / 分度线**：一律**点划线**（`3中心线层`）。
* **中心线长度**：`被标注长度 + 6n`（n = 图框比例），与 `OCSMCENTERLINE` 同一口径。
  * 正视图十字 = `da + 6n`；剖视/侧视的分度线与轴线 = `h + 6n`。
  * （模板里侧视图分度线是 `h+4`、简化视图十字是 `da+4`，属手绘偏差，本命令统一按 6n。）
* **剖视图剖面线**：一个 HATCH、**两个边界环**（轴线上下各一环，范围 = 齿根圆 ↔ 轴线）
  —— 齿部按不剖（GB/T 4459.2）。图案 ANSI31、比例 1.0、角度 0。
* **齿中心相位**：齿中心线在 `齿距/2 + k·齿距`（即齿槽中心在 0°、齿距角处），与模板一致。

## 四、斜齿轮（β≠0）

* 正视图齿廓按**端面参数**画：`mt = Mn/cosβ`、`αt = atan(tanαn/cosβ)`、`d = mt·z`。
* **侧视图**加**三条平行的细实线**（`2细线层`），表示轮齿倾斜方向：
  * 与中心线（轴线）的夹角 = **90° − |β|**；
  * 间距 = **5 mm × k**（k = 视图比例，即图框 `比例`；1:2 图 → 间距 10）；
  * 长度覆盖整个视图；
  * **右旋 `/ / /`**（β 填正数）、**左旋 `\ \ \`**（β 填负数）；
* 剖视图不加这三条线（按用户口径：只在侧视图画）。

## 四之二、内齿轮（齿圈）—— 二期

模板：`~/桌面/OCSM/齿轮/内齿轮.dxf`（m=2 **z=40 h=30**，即齿圈宽度 15m）+
使用示例 `内齿轮使用示例.dxf`。命令：`OCSMGEAR int 2 40 30 view 剖视图`。

### 只有两个视图（模板只有这两个）

| 视图 | 内容 |
| --- | --- |
| **剖视图** | 齿圈轴向剖切：**齿根线（外圆 ±df/2）+ 齿顶线（内孔 ±da/2）+ 孔口 45° 倒角 + 分度线（点划线）**，**共 23 条线**（10 条轮廓×2 侧 + 分度线×2 + 轴线×1）。**不打剖面线** |
| **端视图**（`front`/`端视图`/`常规正视图`） | 真实渐开线**齿槽**轮廓（齿朝圆心长），每齿 8 个实体 + **十字中心线**（长 = df + 6n）。**不画分度圆**（内齿轮模板里没有；外齿轮模板有） |

`侧视图` / `简化正视图` 在内齿轮下**直接报错拒绝**：模板没给这两个视图的画法，
按项目规矩「模板没有的画法不猜」——要加请先给模板。

### 画法要点（反解 + 逐点核对，与模板偏差 ≤ 0.0036 mm）

* **核心结论：内齿轮的*齿槽*形状 = 同参数外齿轮的*齿形*** —— 同一条渐开线、同一个
  `ψ(R) = st/(2r) + (inv αt − inv αR)`，只是这个角要从**齿槽中心线**量。
  （模板核对：m2 z40 时 R=42.076 处 ψ=0.9869°，理论 0.987°）
* 齿顶圆在**内**：`da = d − 2ha`（76）；齿根圆在**外**：`df = d + 2hf`（85）；ρ = 0.38m（0.76）。
* 齿根圆角圆心在 **`rf − ρ`**（外齿轮是 `rf + ρ`）—— 模板实测 41.74。切点是**解出来的**
  （解 `|P(R) + ρ·n(R)| = rf − ρ`），不像外齿轮那样先定齿廓起点再解圆心。
  * 四个根（两法向分支 × 两侧）里挑**圆心落在"它自己半径处齿槽角范围"内**的那个
    （`|Δθ| < ψ槽(|F|)`）—— 只按"谁离中心线近"或"与齿廓同侧"挑都会在 m=10 时挑错。
* 相位：**齿中心在 0°、齿槽中心在半个齿距处**（模板 4.5°），与外齿轮模板的相位约定同构。
* 齿顶弧端点 = **齿中心 ± 齿顶半角**（`pitch/2 − ψ槽`）；根弧两半按两侧圆角切点的**偏移排序**取，
  不能按"−侧在前"写死（圆心跨过齿槽中心线时两边会互换）。

### z ≤ 33 的内齿轮：齿顶圆低于基圆（常见！）

内齿轮 `da = d − 2m`，基圆 `db = d·cos20°` —— `da < db` ⇔ **z < 2/(1−cos20°) ≈ 33.2**。
也就是内齿轮常用齿数（z=24…40）**大部分落在"齿顶圆低于基圆"里**：渐开线下不去，
本命令按简化画法画「渐开线到基圆 → **径向直线**到齿顶圆」，并在提示里说明
（真实齿顶由插齿刀刀尖包络成形，非渐开线；要精确画法请给模板）。

### 剖视图的齿圈外壁：留给用户/AI（用户 2026-09-17 定案）

模板只画到**齿根圆**、**不打剖面线**，因为齿圈外壁结构（轮缘/腹板/键槽/减重孔）随用途变，
一张齿形图要能服务不同齿圈。**延伸画法**（照 `内齿轮使用示例.dxf` 的样板）：

1. 在剖视图里从**齿根线**往外加厚齿圈，轴向宽度保持 `h`（示例：外侧再加 10 mm）；
2. 新轮廓落 **`1轮廓实线层`**、端面/圆角照常；
3. 剖面线：**`5剖面线层` + ANSI31 / 比例 1.0**，**一个 HATCH 两个环**（轴线上下各一环，
   边界是外壁矩形 − 齿根线以内的空腔）—— 与本命令外齿轮剖视图的剖面线口径完全一致。

生成时的提示语里会原文带出这条延伸画法，用户/AI 不用回来翻手册也能接着画。

## 四之三、压力角 α（`alpha=` / `α25`）

默认 **20°**（GB/T 1356 基本齿廓），可给任意 **10°<α<50°** 的值；常用档：
14.5 / 15 / 17.5 / 20 / 22.5 / 25 / 30（渐开线花键）/ 37.5 / 45（DIN/ANSI 短齿）。

α 进入几何的位置（与既有公式一致，没有另立）：

* 基圆 `db = d·cos αt`（直齿 `αt = αn`；斜齿 `αt = atan(tanαn/cosβ)`）；
* 齿廓 ψ(R) 里的 `inv αt`（`αR = acos(rb/R)` 随 db 变）；
* 分度圆端面齿厚 `st = πMn/(2cosβ) + 2Xn·Mn·tanαn`（变位项随 α）。

**不随 α 自动变的量（用户按所用标准手动给）**：齿顶高系数 `ha*`、顶隙系数 `c*`、
齿根圆角系数 `ρ = 0.38m`。14.5° 老系统、45° 花键等请用 `ha=` / `c=` 显式指定。

**齿顶变尖（大 α 的限制）**：外齿轮用全齿高 `ha*=1` 时，当 `2·ha*·tanα ≳ π/2`
（约 α>38.15°），两条渐开线在齿顶圆之前就相交，`ψ(da/2) ≤ 0`。
本命令不硬画（会出一张齿顶勾连线、无法加工的乱图），而是：

* **常规正视图**明确报错 `齿顶变尖/渐开线交叉…`；
* **剖视图 / 侧视图 / 简化正视图**照常生成（它们只用 d/da/df，不受齿廓影响）；
* `notes` 里给出修复指引（减小 ha*，45° 花键常用 ha*=0.5，或减小 α/增大 z）。

例：`OCSMGEAR m=2 z=40 h=20 alpha 45 ha=0.5 view 常规正视图`。

## 五、变位齿轮（Xn≠0）

* `da = d + 2Mn(ha* + Xn)`、`df = d − 2Mn(ha* + c* − Xn)`；
* 齿厚（端面）`st = πMn/(2cosβ) + 2Xn·Mn·tanαn`，齿廓整体绕中心偏转相应的半角；
* 齿顶高**不扣齿顶高变动系数 Δy**（单件图没有配对中心距信息，需要时按配对中心距另算）。
* `z < 17` 且 `Xn = 0` 时会在提示里提醒"实际滚齿会有根切，本视图未画根切"。

## 六、生成物是什么

* **块**：名字形如 `OCSM_GEAR_M2_Z40_H20_SECTION`（**非默认压力角加 `_A25`/`_A37_5`**，同一件 20° 与 25° 不会命中同名块；斜齿轮加 `_B8R`/`_B8_5L`，变位加 `_X0_3`/`_XN0_25`），
  与标准件块同风格；同名块**幂等复用**（同参数同视图只建一次）。
* **摆放**：块插入（`INSERT`）落在 `1轮廓实线层`，插入点 = 你点/给的点，旋转 = 你标的角度；
  一次生成 = **一次 Ctrl+Z 撤销**。
* **台账**：插入实体带 XDATA `OCSM_PART`（app 名同标准件），里面记 `family=gear`、m/z/α/ha*/c*/β/h/Xn、
  视图、规格文本、**毛坯质量**（实心、不含轴孔；明细表里如需要请按实际孔型修正）。
* **没有尺寸标注**（与标准件一致：图元只落 OCSM 图层，不生成标注）。

## 七、注意事项 / 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 报“这张图还没跑过 OCSM 初始化” | **先运行 `OCSM`**（或功能区「图幅」组里的初始化）再画齿轮；这是故意的拦截，不是 bug |
| 提示“齿根圆角无解…已按…降级出图”（**外齿轮**） | 齿数太小，0.38m 圆角要不下（`\|rf+ρ − 齿廓起点\| > ρ`）。已自动降级（FreeCAD 口径：基圆以下直线+圆角），图形不会乱；要真实形状请用变位 |
| 提示“内齿轮齿根圆角无解”（**内齿轮**） | 内齿轮圆角是"解"出来的（圆心在 rf−ρ），解不出才提示：已按无圆角画（齿廓末端径向直线落到齿根圆）。与外齿轮的降级是两套逻辑，别混 |
| 小齿数齿根看起来是“直线+小圆角”而不是凹的根切曲线 | 同上，降级口径（FreeCAD `fcgear` 就是这么画的）。真实根切曲线 = 刀尖圆角中心次摆线的等距线，需刀具相位标定，二期可做 |
| 内齿轮报“不提供「侧视图」视图” | 内齿轮模板只有剖视图+端视图，故意拒绝（模板没有的画法不猜）。要加请给模板 |
| 内齿轮剖视图里找不到剖面线 | **故意不画**：齿圈外壁结构留给用户/AI 延伸后再打；延伸画法见第四节之二 |
| 内齿轮提示“齿顶圆…低于基圆” | z≤33 的正常提示，已按简化画法（径向直线收到齿顶圆）出图，不是 bug |
| 斜齿轮画出来齿廓比直齿"胖一点" | 正常：分度圆 `d = Mn·z/cosβ` 比直齿大 |
| 报“齿顶变尖/渐开线交叉” | α 太大配了全齿高（如 45° + ha*=1）：减小 `ha=`（45° 花键常用 0.5）或增大 z；剖视/侧视/简化正视图不受影响 |
| 侧视图看不到三条细线 | β=0（直齿）不画；只填了分度/秒没填度数也会被视为 0 |
| 中心线比图纸里的老图长一点 | 老图按 `+4` 手绘，本命令统一按国标口径 `+6n` |
| 剖视图没有倒角台阶线，侧视图有 | 按模板：全剖视图省略该棱边 |
| 生成的图偏大/偏小 | 齿轮按**真实尺寸**画；图纸比例由图框（`TF`）控制，中心线/细线间距才跟比例走 |

## 九、渐开线花键（`detail_invol_spline` / 轴段 `INVOLSPLINE`）

> 渐开线花键与齿轮同是渐开线齿廓，但不是齿轮：它按花键标准（GB/T 3478.1-2008 /
> DIN 5480-1:2015）的基本齿廓与配合口径出图。核心几何在 `src/invol_spline.rs`，
> 两个入口共用：**XL 结构要素**（独立出图，三视图）与**轴生成器段**（轴侧视图）。

### 两个入口的写法

- 独立要素：`XL detail_invol_spline <预设代号> M<模数> Z<齿数> [X<变位>] [DB<基准直径>] [L<有效长度>] [view front|side|section]`
  （例 `XL detail_invol_spline GB30R M3 Z20 L30 view side`；正视图不需要 L）。
  **DIN 主路径**：`DIN30 DB40 M2 L30`（给 `DB` 后 `M`/`Z` 可缺一项，由 DIN 5480-2 表补全）。
- 轴生成器段：`INVOLSPLINE <预设代号> [DB40] M3 Z20 [X0.2] L30 [de63]`
  （例 `OCSMSHAFT S30 E30 L50 | INVOLSPLINE DIN30 DB40 M2 L30 | S30 E30 L10`；
  也收 `DB 40` / `DB=40`）。与 `SPLINE` 一样：**不能**与 CH/OV/RL/M/GEAR/SPLINE 同段
  （引入倒角写在相邻轴段的 CH 上）。
- 两个 GUI（零件库 / 轴生成器）都有：**标准预设下拉（GB/DIN）+ 齿廓下拉 + m/z/x/L 输入**；
  DIN 另加 **d_B 输入（带 DIN 5480-2 名义表候选下拉）**，选/填 d_B 后自动带出 m/z/x；
  实时显示 `d_B/d/z/m/x` 与 `d/db/da/df/ρf/cF`，并注明数据来源（查表命中 pNN / 公式解出）；
  段表 ↔ 行文本/JSON 同步。

### 预设与口径

| 标准 | 齿廓（代号） | α | ha* | hf* | ρf* | cF* |
| --- | --- | --- | --- | --- | --- | --- |
| GB/T 3478.1 | 30°平（`GB30P`）/30°圆（`GB30R`，默认）/37.5°圆（`GB375R`）/45°圆（`GB45R`） | 30/37.5/45 | 0.5/0.45/0.4 | 0.75/0.9/0.7/0.6 | 0.2/0.4/0.3/0.25 | 0.1 |
| DIN 5480-1 | 30°圆（`DIN30`） | 30 | 0.45 | **0.55** | 0.16 | 0.1 |

- **DIN `hf*=0.55` 的依据**：DIN 5480-1:2015 条 5.1 —— 齿侧对中（Flank centering）时
  `h_fP = 0.55·m` 是基准；滚刀加工 −0.1m、插齿刀 ±0.2m 属刀具相关修正，需要时用
  `InvolParams::with_coeffs` 覆盖。取 0.55 后 `d_f1 = mz+2xm−1.1m` 与 DIN 5480-2
  名义表逐行吻合（m=0.5、x·m=0.225：z=34 → 16.90，z=10 → 4.90），旧值 0.60 会差 0.1m。
- 直径一律按标准公式：`d=mz`、`db=d·cosα`、外花键 `da=mz+2xm+2ha*m`、`df=mz+2xm−2hf*m`、
  齿厚 `s=mπ/2+2xm·tanα`；DIN 变位范围 `x∈[−0.05, 0.45]`（`validate` 拦超界）。
- **DIN `d_B`（基准直径）主路径 = 查表**：数据源 DIN 5480-2:2015-03 名义表，已入库
  `crates/ocs_ocsm/assets/din5480_2_nominal.csv`（618 行，源 665 行剔除 p35/m=5 整页 47 行；
  **m=1.5 缺失**（p23/p24 源图空表框）、**m=5 已剔除**（p35 渲染缺陷），见同目录 `din5480_2_notes.md`）。
  `lookup_by_d_b(d_B, m?)`：同一 `d_B` 可能有多个 `z/x₁` 变体（返回多行是表格事实）；
  未命中列附近候选；命中缺失档位明确报「该档位数据缺失」。
- `d_B` 与 `m/z/x` 的换算（**从 OCR 表反推并经全表 618 行校验**，不是标准原文公式）：
  `x = (d_B − m(z + 1.1)) / (2m)`，等价 `d_B = d + 1.1m + 2x·m`、`z_B = z + 1.1 + 2x`。
  `DB+M` 补 Z、`DB+Z` 补 M、`DB+M+Z` 解 X 并与表值互相印证（不一致报错）；
  未命中表时按公式解出并在结果里注明「由公式解出，未命中表」。
  旧 `d_B_estimate = m(z+2x)` 仅作兼容保留，不是 `d_B` 定义式。

### 视图与落层

- `front` 端视图：每齿**真实渐开线**（`INVOLUTE_SEGMENTS=12` 折线）+ 齿顶/齿根弧 + 十字中心线
  （相位：齿槽心线 0°+k·360°/z，与矩形花键同）；该视图**不画**齿根过渡圆角弧（ρf 只导出数值）。
  齿顶变尖（`ψ(da/2)≤0`）或齿槽过宽（相邻齿廓在齿根前相交）会**明确报错**，不硬画乱图。
- `side` / `section` 侧视/侧剖：矩形 `L×da` + 小径线（常规 `2细线层`；剖视改 `1轮廓实线层` +
  轴线↔小径两条带 ANSI31 剖面线）。
- 轴段 `INVOLSPLINE`：`s=e=da`、段长 = `L`（不给 `de`）或 `L+l`（给 `de`，
  `l=√(h(2R−h))`、`R=de/2`、`h=(da−df)/2`，与 `SPLINE` 同式）；小径细线只到 `x=L`，
  给了 `de` 才画收尾弧。**只做外花键**；内花键只有数值接口 `internal_tip_dia()`。
