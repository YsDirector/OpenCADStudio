# 16 齿轮（`OCSMGEAR` / `CL`）—— 一期：外齿轮

> **前置要求**：先跑过 `OCSM` 初始化（建 10 图层 + 线型 + 文字/标注样式）。
> 没初始化的图纸执行 `OCSMGEAR` 会**直接拦下来并报缺什么**（用户 2026-09-17 定案）；
> 不然切出来的图“中心线是实线白线、剖面线层颜色也不对”。
>
> 参数化画**圆柱齿轮**（直齿 / 斜齿、可带变位），一次出一个视图，四个视图任选：
> **剖视图 / 侧视图 / 简化正视图 / 常规正视图**。
> 放置方式与 `XL`（标准件）**完全一样**：窗口里「生成到图纸」→ 回图纸点基点 →
> 移动光标旋转 → 再点落定（可连续，Esc 结束）。
>
> **一期只画外齿轮**；内齿轮二期（等外齿轮验收后做）。
> 画法唯一权威 = 用户模板 `~/桌面/OCSM/齿轮/齿轮画法.dxf`（m=2 z=40 h=20），
> 本命令的每个构造规则都是从那张图反解并逐点核对出来的。

## 一、两种用法

| 用法 | 命令 | 结果 |
| --- | --- | --- |
| 人用（推荐） | `OCSMGEAR`（或 `CL`） | 打开**齿轮窗口**：左上预览 + 4 个视图按钮 + 参数表单；点「生成到图纸」后鼠标带图，点击放置 |
| AI / 脚本 | `OCSMGEAR <m> <z> [h] [键=值…] [view 视图] [at x,y] [rot 度]` | 直接生成并插入（`at` 给了就落在该点，否则落在待放置点/原点） |

参数键（命令行与窗口同一套）：

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `m`（第 1 个位置参数） | 法向模数 Mn（斜齿轮就是 Mn） | — |
| `z`（第 2 个） | 齿数 | — |
| `h`（第 3 个 / `h=`） | 厚度（齿宽） | `10×m` |
| `ha=` | 齿顶高系数 ha* | `1` |
| `c=` | 顶隙系数 c* | `0.25` |
| `beta=` | 螺旋角 β（**度**，右旋为正、左旋为负；0 = 直齿） | `0` |
| `x=` | 变位系数 Xn | `0` |
| `view` | `剖视图`/`section`、`侧视图`/`side`、`简化正视图`/`simplified`、`常规正视图`/`front` | `剖视图` |
| `at x,y` | 插入点 | 待放置点或原点 |
| `rot 度` | 旋转角（逆时针，度） | `0` |

例：

```
OCSMGEAR 2 40 20                                  ← 剖视图（默认），落在待放置点
OCSMGEAR 2 40 20 view 常规正视图 at 300,200        ← 常规正视图，落在 (300,200)
OCSMGEAR m=3 z=25 h=30 beta=-8 x=0.2 view 侧视图
```

## 二、四个视图分别是什么

| 视图 | 内容 | 什么时候用 |
| --- | --- | --- |
| **剖视图** | 齿顶圆柱（带轴向倒角）+ **齿根线** + 分度线（点划线）+ 轴线 + **剖面线**（ANSI31，轴线上下一共两个环：齿根圆↔轴线） | 装配图/零件图主视图，最常用 |
| **侧视图** | 同上但**不剖**：无齿根线、无剖面线；斜齿轮多**三条细实线**表示轮齿倾斜方向 | 与剖视图配对；斜齿轮必看 |
| **简化正视图** | 齿顶圆（粗实线）+ 分度圆（点划线）+ 齿根圆（细实线）+ 十字中心线 | 快速表达、装配图 |
| **常规正视图** | 真实**渐开线**齿廓（每齿 8 个实体）+ 分度圆 + 十字中心线 | 需要真齿形时（线切割、检验） |

## 三、画法要点（都从模板反解，不是手册臆造）

* **齿廓**：渐开线（α=20°），用 **clamped 3 次 B 样条**表示，每条齿廓 **7 个控制点**
  —— 拟合点取在 `r = rb + (ra−rb)·{1/8, ¼, ½, ¾, 1}`（5 点），节点按**弦长参数化**。
  模板实测：全 80 条样条对理论渐开线最大偏差 0.012°（≈9 µm），本实现 ≈5 µm。
* **精度是硬约束**：这套"每齿 8 实体 / 齿廓 7 控制点"是用户验证过的**兼顾加工与性能**的最佳平衡，
  **不要提高精度**（试过更高精度，电脑带不动）。
* **齿根过渡圆角**：ρ = **0.38m**（GB/T 1356）；圆心在 `r = rf+ρ` 上，并且**到齿廓起点的距离 = ρ**
  （只与齿根圆相切，与齿廓"搭上"）。
* **轴向倒角**：`C = round(0.6m)`（用户定案），45°，落在**齿顶圆柱两端**；
  齿顶面长度 = `h − 2C`，端面线画到 `±(da/2 − C)`。
  * 侧视图有两条**倒角台阶线**（`x = ±(h/2 − C)`）；
  * **剖视图没有这两条**（模板就是这么画的，全剖时该棱边省略）。
* **分度圆 / 分度线**：一律**点划线**（`3中心线层`）。
* **中心线长度**：`被标注长度 + 6n`（n = 图框比例），与 `OCSMCENTERLINE` 同一口径。
  * 正视图十字 = `da + 6n`；剖视/侧视的分度线与轴线 = `h + 6n`。
  * （模板里侧视图分度线是 `h+4`、简化视图十字是 `da+4`，属手绘偏差，本命令统一按 6n。）
* **剖视图剖面线**：一个 HATCH、**两个边界环**（轴线上下各一环，范围 = 齿根圆 ↔ 轴线）
  —— 齿部按不剖（GB/T 4459.2）。图案 ANSI31、比例 1.0、角度 0。
* **齿中心相位**：齿中心线在 `齿距/2 + k·齿距`（即齿槽中心在 0°、齿距角处），与模板一致。

## 四、斜齿轮（β≠0）

* 正视图齿廓按**端面参数**画：`mt = Mn/cosβ`、`αt = atan(tanαn/cosβ)`、`d = mt·z`。
* **侧视图**加**三条平行的细实线**（`2细线层`），表示轮齿倾斜方向：
  * 与中心线（轴线）的夹角 = **90° − |β|**；
  * 间距 = **5 mm × k**（k = 视图比例，即图框 `比例`；1:2 图 → 间距 10）；
  * 长度覆盖整个视图；
  * **右旋 `/ / /`**（β 填正数）、**左旋 `\ \ \`**（β 填负数）；
* 剖视图不加这三条线（按用户口径：只在侧视图画）。

## 五、变位齿轮（Xn≠0）

* `da = d + 2Mn(ha* + Xn)`、`df = d − 2Mn(ha* + c* − Xn)`；
* 齿厚（端面）`st = πMn/(2cosβ) + 2Xn·Mn·tanαn`，齿廓整体绕中心偏转相应的半角；
* 齿顶高**不扣齿顶高变动系数 Δy**（单件图没有配对中心距信息，需要时按配对中心距另算）。
* `z < 17` 且 `Xn = 0` 时会在提示里提醒"实际滚齿会有根切，本视图未画根切"。

## 六、生成物是什么

* **块**：名字形如 `OCSM_GEAR_M2_Z40_H20_SECTION`（斜齿轮加 `_B8R`/`_B8_5L`，变位加 `_X0_3`/`_XN0_25`），
  与标准件块同风格；同名块**幂等复用**（同参数同视图只建一次）。
* **摆放**：块插入（`INSERT`）落在 `1轮廓实线层`，插入点 = 你点/给的点，旋转 = 你标的角度；
  一次生成 = **一次 Ctrl+Z 撤销**。
* **台账**：插入实体带 XDATA `OCSM_PART`（app 名同标准件），里面记 `family=gear`、m/z/ha*/c*/β/h/Xn、
  视图、规格文本、**毛坯质量**（实心、不含轴孔；明细表里如需要请按实际孔型修正）。
* **没有尺寸标注**（与标准件一致：图元只落 OCSM 图层，不生成标注）。

## 七、注意事项 / 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 报“这张图还没跑过 OCSM 初始化” | **先运行 `OCSM`**（或功能区「图幅」组里的初始化）再画齿轮；这是故意的拦截，不是 bug |
| 提示“内齿轮二期” | 一期只做外齿轮，`kind=internal` 暂不支持 |
| 斜齿轮画出来齿廓比直齿"胖一点" | 正常：分度圆 `d = Mn·z/cosβ` 比直齿大 |
| 侧视图看不到三条细线 | β=0（直齿）不画；只填了分度/秒没填度数也会被视为 0 |
| 中心线比图纸里的老图长一点 | 老图按 `+4` 手绘，本命令统一按国标口径 `+6n` |
| 剖视图没有倒角台阶线，侧视图有 | 按模板：全剖视图省略该棱边 |
| 生成的图偏大/偏小 | 齿轮按**真实尺寸**画；图纸比例由图框（`TF`）控制，中心线/细线间距才跟比例走 |

## 八、想改画法怎么办

1. 先改 **`crates/ocs_ocsm/src/gear.rs`** 顶部那段的表格（规则 → 核对值）；
2. 单测里有模板实测值（`template_basic_dimensions` / `flank_fit_points_match_template` /
   `fillet_is_tangent_to_root_and_touches_flank` / `section_view_has_two_hatch_loops_and_root_lines` …），
   改完跑 `cargo test -p ocs_ocsm --lib gear::`；
3. 出图比对：`cargo test -p ocs_ocsm --lib gear::tests::dump_views_csv -- --ignored --nocapture`
   把四个视图导到 `/tmp/gear_review/*.csv`，可与 `齿轮画法.dxf` 直接叠加核对。
