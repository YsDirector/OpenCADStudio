# 02 图幅与图框

> 建图幅、换图框、按比例出图。

## 一、两步流程

```
第 1 步：OCSMFRAMEINIT（不带参数）→ 打开「图框选择窗口」
第 2 步：OCSMFRAMEINSERT  → 选比例后，在图纸里点插入点落图框
```

## 一、两种用法

### A. 人侧：两步（选择窗口）

```
第 1 步：OCSMFRAMEINIT（不带参数）→ 打开「图框选择窗口」
第 2 步：OCSMFRAMEINSERT  → 选比例后，在图纸里点插入点落图框
```

### B. AI/自动化侧：一行直插（**不开选择窗口**）

```
OCSMFRAMEINIT <名称> [比例] [at x,y] [rot 度]      （OCSMFRAMEINSERT 同语法）
```

| 写法 | 效果 |
| --- | --- |
| `OCSMFRAMEINIT a3_landscape_att 1:2 at 0,0` | **全自动**：直接插一张 1:2 的 `a3_landscape_att`，基点 (0,0) |
| `OCSMFRAMEINIT a3_landscape_att 1:2` | 定好图框+比例 → 进**光标跟随**放置（点一下落定） |
| `OCSMFRAMEINIT a3_landscape_att` | 图框 + 1:1 + 光标跟随 |
| `OCSMFRAMEINIT 1:2 at 0,0` | **名称可省**（`frame/` 里只有唯一图框时） |
| `OCSMFRAMEINIT a3_landscape_att 1:2 at 0,0 rot 90` | 顺带旋转 90° |

* **名称**：`frame/` 里的 dwg 文件名（可省 `.dwg`、大小写不敏感，也可只写其中一段如 `landscape`）。
  精确名优先；只写一段而匹配到多个 → 报错并列出现有图框。
* **比例**：`1:2`、`1：2`（全角冒号）、`1/2`、或光写 `2`（= 缩小 2 倍）；放大写 `2:1` 或 `0.5`。
  规则同选择窗口：**两个正整数且其一为 1**。
* **坐标**：`at x,y`（`at` 可省，直接写 `x,y`；也收 `x,y,z`）。
* 报错都带用法提示：
  ```
  OCSMFRAMEINIT：比例必须是两个正整数且其一为 1（例 1:2 / 2:1 / 1:1）。
  OCSMFRAMEINIT：没有叫「a2」的图框。现有：a3_landscape_att / a4_portrait。
  OCSMFRAMEINIT：认不出的参数「乱写」。用法：OCSMFRAMEINIT <名称> [比例] [at x,y] [rot 度]（不带参数 = 打开选择窗口）
  ```
* 自动化里推荐**先 `cancel` 再发命令**（避免交互态残留）：

```jsonc
{ "op": "run", "request_id": "f1", "document_id": 1, "revision": 3,
  "cmd": "OCSMFRAMEINIT a3_landscape_att 1:2 at 0,0" }
```

### 第 1 步 `OCSMFRAMEINIT`（人侧）：选图框

- 从**插件目录**的 `frame/` 顶层列出 `*.dwg`（按文件名排序；不递归扫描子目录），窗口里点选即可。
  - 实际路径：`~/.config/OpenCADStudio/plugins/opencad.ocsm/frame/`
  - 中间版/备用图框须放入独立子目录（例如 `frame/_intermediate/`），不要与可选模板并排放在 `frame/` 顶层；`OCSMFRAMEINIT` 只发现顶层 DWG，但分目录可避免误选并保护中间版。
  - 当前可选模板：`a3_landscape_att.dwg`（A3 横式，含 **185×40 标题栏** + 左侧竖向附加栏）；以目录实际内容为准。
- **图框 DWG 是用户自备数据，不在插件仓库里**（仓库 `crates/ocs_ocsm/` 下没有 `frame/`）：
  - 样例图框在维护机上位于 `~/桌面/OCSM/frame/`，装机前用 `tools/frame_clean.py --install` 清洗
    （去旧环境残留图层/字典 + 修图层颜色）后写进插件目录的 `frame/`；
  - 图框里的文字样式 `OCSM_GB` 与插件 `text_style_defs()` **同口径**（用户 2026-09-28 定案：
    以插件为准）：group 3 = TTF 名（`Zhuque Fangsong`，不是 SHX 占位的 `Unicode`）、宽比 0.7、
    `height = 3.5`（模板原来写 0.0 = 不定高）、`annotative = 1`。`tools/frame_clean.py`
    按这套参数产出，并自检查图框 DWG；其中 `annotative` 走 XDATA `AcadAnnotative`，
    LibreDWG 写 DWG 时会丢，插框时由插件 `ensure_text_styles()` 兜底对齐。
  - 新机器部署：把图框 DWG 放进上面的 `frame/`，或部署时给 `tools/deploy_plugin.sh` 传
    `OCSM_FRAME_SRC=<放图框的目录>`（同名不覆盖已装图框）；
  - 部署脚本自检里 `frame/` 为空**默认只警告 + `rc 0`**（图框是用户自备数据，脚本不生成，也不该
    拦住新用户）——因为空目录下 `OCSMFRAMEINIT` 只会报「找不到图框文件夹」；要把它当硬门禁（发布/CI）
    就显式设 `OCSM_REQUIRE_FRAME=1`（此时才非零退出）。
- 目录不存在/为空时报：`OCSMFRAMEINIT: 找不到图框文件夹 …。请在插件目录的 frame/ 中放入 DWG。`
- 这一步只是**登记选择**，还没往图纸里放东西 → 接着跑 `OCSMFRAMEINSERT`。

### 第 2 步 `OCSMFRAMEINSERT`：按比例插入

- 参数：**比例两个正整数，且其一必须为 1**（`1:1`、`1:2`、`2:1`…）。非法比例报
  `OCSMFRAMEINSERT: 非法的比例（必须为两个正整数且其一为 1）。`
- 没先运行 `OCSMFRAMEINIT` 报：`OCSMFRAMEINSERT: 没有待处理的图框选择。请先运行 OCSMFRAMEINIT。`
- 插件会：
  1. 计算缩放系数 `scale = scale_v2 / scale_v1`；
  2. **不预创建缩放标注样式**；实际生成标注时，`OCSMDIMGULIDE` / `OCSMDIM2GB` 按标注锚点所在图框比例按需创建对应的 `OCSM_GB_xN`，保证标注尺寸与图框比例一致；
  3. 导入图框块（含 ATTDEF 标题栏属性）；
  4. 进**光标跟随**交互：移动鼠标带图框预览 → **点一下落定**。
- 落定后标题栏属性（图名/图号/材料/比例/重量等）可直接双击 ATTDEF 编辑，或用宿主属性编辑。

## 标题栏签审约定（本机 A3 模板，2026-10-27）

本机模板使用以下角色映射；这是本工作流约定，不宣称所有国标图框必须有同样栏位：

| 工作流角色 | 图上栏位 / tag | 英文 prompt |
| --- | --- | --- |
| 设计（主 Agent + 自查） | 设计 | DESIGN |
| 校对（形式/图面规范审查） | **标准化** | STANDARD |
| 审核（工程合理性） | 审核 | REVIEWED |
| 批准（人工） | **批准**，位于主标题栏日期正上方，与审核同行 | APPROVED |
| 材料 | 材料 | **MATERIAL**，不再用 PRODUCT_NAME |

- 不新增「校对」栏。校对通过写「标准化」实际值；审核先验证同一图框实例的「标准化」签名，失败需使标准化与审核失效；批准必须由人确认。
- 署名用模型家族短名；模型全名、图纸版本和审查证据另存报告。签名只改目标 **INSERT 的属性值**，不能改共享 ATTDEF 或把空属性时显示的 tag 当成已经签名。
- 正式安装模板原为 20 个 ATTDEF，新增批准后 21 个。空白图单次插入核对的是 **1 个 INSERT + 21 个实例属性**；块定义中的 ATTDEF 不应再加算为第二套实例。日期、图样代号在左附加栏与主标题栏各一处属于不同用途。
- 桌面 `frame/clean/` 中间副本曾有 40 个 ATTDEF，不代表正式模板，不得据此删正式模板字段或用旧副本覆盖新模板。修改前原件备份 `a3_landscape_att.dwg.bak-20261027-171902`。
- 本轮专用 `OCSMFRAMEINIT ... at ...` 自动化通道报 `import_frame_block: not supported by this host`；原生 `-INSERT` 单次插入与 DWG 2000 `save_verified` 往返验证通过。前者仍是待查宿主兼容问题，不能据后者声称已修好。

## 二、比例与标注的关系（关键概念）

| 概念 | 在哪 | 说明 |
| --- | --- | --- |
| **图形比例** | 图框块缩放 | 几何仍 1:1 画；**不要**把图形缩到图框里 |
| **标注文字高度** | `OCSMDIMGULIDE` / `OCSMDIM2GB` 在实际标注锚点按需创建的 `OCSM_GB_xN` | 标注按锚点所在图框比例取样式；打印后字高仍按纸面口径保持为 5 |
| 标题栏"比例"格 | 图框 ATTDEF | 手填/改，如 `1:2` |

> 出图时按图框实际尺寸（A3 = 420×297）打印；因为几何 1:1，图框放大了 N 倍就是把"图纸"放大 N 倍，
> 所以标注样式也跟着放大 N 倍。

## 三、AI 侧配方

```jsonc
// 1) 打开图框选择窗口（人类点选；AI 驱动时这一步要人配合）
{ "op": "run", "request_id": "f1", "document_id": 1, "revision": 3, "cmd": "OCSMFRAMEINIT" }
// —— 人在窗口里选好图框、填比例、点"确定" ——
// 2) 插入（进光标跟随；AI 无法点鼠标 → 需要人类点，或由宿主 run 带点坐标）
{ "op": "run", "request_id": "f2", "document_id": 1, "revision": 4, "cmd": "OCSMFRAMEINSERT" }
// 3) 核对：图框块 + 标题栏 ATTDEF
{ "op": "read", "op": "query", "parameters": { "type": "Insert" } }
```

> AI 驱动时若无法点击：把图框当"人类环节"交给用户（或后续用无头模式导入图框块并自己缩放到目标尺寸）。

## 四、坑

1. **`OCSMFRAMEINIT` 后忘了 `OCSMFRAMEINSERT`**：只有登记，没有实体。
2. **比例写反**：`1:2` = 图形放大 2 倍放图框（缩小比例出图）；`2:1` = 图形缩小一半。按国标意图选。
3. **图框自带的图层/样式**：导入的图框块会带它自己的图层（如"图框线"），这是**正常**的——
   OCSM 的 10 层管的是零件几何，不必把图框搬到 `1轮廓实线层`。
4. **明细表位置依赖图框几何**：BOM 的右边界/宽度/底边是从图框量出来的（内框右边、标题栏宽、标题栏上沿），
   换图框后明细表位置要重新对（见 `10-明细表BOM.md`）。

## 五、验证清单

- [ ] `frame/` 里有你要的图幅 dwg（文件名 = 窗口里的标签）。
- [ ] 插入后 `query Insert` 能看到图框块；标题栏 ATTDEF 能编辑。
- [ ] 插入图框本身不预创建 `OCSM_GB_xN`；在缩放图框内的实际标注锚点运行 `OCSMDIMGULIDE` 或 `OCSMDIM2GB` 后，样式按需出现且新标注使用它。
