# 25 知识：铸造箱体（减速器壳体）设计快查

> 面向"箱体是铸出来的"这条路线：轮廓怎么定、凸台怎么长出来、安装面怎么画、顺序怎么排、怎么验收。
> 本篇内容来自二级圆柱齿轮减速器 V4 工作稿（候选 17–44）的实际返工记录，全部是踩过坑的结论。

## 一、先分清"焊接语言"和"铸造语言"

| 特征 | 焊接箱体 | 铸造箱体 |
| --- | --- | --- |
| 外形 | 矩形板 + 型钢，直线为主 | 随内部齿轮/轴承外圆走：**同心圆弧 + 外公切线**，整体是连续曲线 |
| 加强 | 焊筋、角钢 | 侧壁整块板，**铣减重窗口**，窗口之间剩下的肉就是筋 |
| 凸台 | 焊/螺栓连接件 | 从壁面**长出来**，与壁/座连续，不能是贴上去的独立圆柱或方块 |
| 底座 | 型钢底框 | **水平底座**，底面必须平（Z 不变） |

判据：矩形内腔 + 直角法兰 = 焊接语言；要在图上画铸造箱体，轮廓必须先换成圆弧包络。

## 二、总体轮廓（二级齿轮减速器）

1. **上半部（Z>0）**：取各齿轮齿顶圆（G1/G2/G3/G4）、各轴承座凸台圆的**凸包**（相邻圆外公切线连接），
   内腔再向内偏置壁厚，外轮廓向外偏置壁厚。本项目：壁厚 10，齿顶 +6 留隙，轴承座凸台 `R = D/2 + 16`。
2. **下半部（Z<0）**：不能延用圆弧包络，否则底面是弧的、无法安装。
   取该高度处的最大宽度**竖直下延**到外底（本项目 Z=−150），油池底 Z=−140，底面为水平面。
3. **剖分法兰**：外轮廓外扩（X–Z 方向），但 **Y 向只外伸到端盖座面为止**，
   否则法兰会盖住端盖安装面（本项目外伸 55 时端盖装不进去，改 30 才对）。
4. **筋**：每座一条、中心对轴线、上端嵌入凸台外圆、下端接底板顶面；宽 24、外凸 8（名义值）。

## 三、端盖安装面（座台）——本项目返工最多的一处

### 3.1 形状：曲边梯形，两条腰＝相邻座外圆

```
        ┌──────── 座面（水平，Z=H）────────┐
       ╱                                  ╲
  腰＝座Ⅰ/Ⅱ外圆 R 的圆弧          腰＝座Ⅱ/Ⅲ外圆 R 的圆弧
     ╱                                      ╲
 ───┴──── 剖分面 Z=0（两座之间的空档）────┴───
```

- 两条"腰"**就是**相邻轴承座（端盖法兰）外圆的圆弧本身，`R = D/2 + 16`；
- 座台侧面与座圆面**重合**，融合后是同一张圆柱面 → **不可能出现"立方塔"、竖壁、薄片、尖谷**；
- 座面宽度由圆弧决定，不是人为给的常数；
- 底边落在剖分面 Z=0，宽度＝两座之间在该高度的空档。

### 3.2 为什么不用"竖直壁 + 根部大圆角"

竖直壁会露在座圈之上，永远读作"方块塔"；根部圆角在融合体上事后做（`Shape.makeFillet`）还会直接
报 `BRep_API: command not done`。要么把圆角画进轮廓，要么干脆不要竖壁——曲边梯形属于后者。

### 3.3 座面高度 H（扳手空间）

判据（JB/ZQ 4005—1997：M12 的 `A=42` 开口扳手、`A2=30` 梅花/套筒，按"螺栓轴线到障碍的径向距离"取）：

```
扳手头下表面 = 座面 + 垫圈厚（本项目 2.5）
要求：  d − √(rb² − (H+2.5)²) ≥ A
```

- `d` = 螺栓轴线到相邻座轴线距离，`rb` = 相邻座外圆半径；
- **H 必须小于相邻两座的半径**，否则圆弧到不了座顶、腰线断开，曲边梯形不成立；
- 本项目：X=62（Ⅱ 座 rb61，d71.75）→ H≥50.75 取 **51**；X=201（Ⅲ 座 rb71，d78.25）→ H≥58.55 取 **59**；
- 若只按梅花/套筒，可降到 ~45/50；只按套筒（外径 22~24）可降到 ~23。**先把工具定死再算 H。**

## 四、顺序：安装面先，孔后

这是本项目最后一处、也是最典型的返工根因。

**正确顺序**

1. `Sketch`（曲边梯形）+ `Pad` —— 先把**整块端盖安装面**做出来；
2. `Pocket` 剖分螺栓孔（本项目 Ø13.5）；
3. `Pocket` 轴承座孔系（座孔 ØD、挡肩、通孔）；
4. `Pocket` 端盖螺钉孔（Ø6.8×14，从安装面向里钻）；
5. 清理"旧时代"的遗留特征（例：原有 Ø30 锪平沉窝 → 新座面是平面，已无意义，要填实）。

**反例（真实发生）**：先有平面的安装面 + Ø30 锪平沉窝，后把安装面整体抬高。新座台在 Z=10…22 只有
13.5 mm 宽（两座圆近相切），盖不住 Ø30 沉窝的两翼 → 剖视图上露出两块真空腔
（X 190…193 / 209…211，Z 10…21），看起来就是"两个洞"。

**推论**：凡是"安装面形状会变"的改动，之前基于旧安装面做的孔/窝/台阶都要一并重做或填实；
否则新面越窄，旧特征露头越多。

## 五、凸台、拔模、圆角（铸造习惯）

- 座台/凸台侧面要给 **1°–2° 拔模**（用曲边梯形时，圆弧面本身即模具分型方向上的自然面）；
- 根部圆角、窗口棱边倒钝（R2–R3）**画在轮廓/草图里**，不要事后 `makeFillet`；
- 壁厚均匀优先；实心大块（如座台）要单独作热节/凝固校核，不能只看"画得下去"；
- 减重窗口：宁可少开、留厚边，也不要出现 <8 mm 的窄条——铣刀进不去、铸造也易粘砂。

## 六、验收（几何层，可自动化）

| 检查 | 做法 | 判据 |
| --- | --- | --- |
| 单实体 | `len(shape.Solids)==1 and shape.isValid()` | 上下半箱体各自成立 |
| 空腔扫描 | 在座台中间平面按 1 mm 网格 `isInside`，排除该钻的孔（螺栓孔/轴承孔/端盖孔） | 0 个非预期空腔 |
| 座面平整 | 垫圈环形区下方点实心、上方点空 | 全部成立 |
| 接口不新增干涉 | 与端盖/轴承/轴做 `common()`，比较改前改后体积 | 不新增正体积 |
| 其余零件未动 | 逐件包围盒/体积/面数签名 | 完全一致 |
| 紧固件 | 与箱体零干涉、垫圈支承率=1.0 | 全部成立 |

> `common()` 返回空拓扑时是"未判定"，**不是零干涉**；必须改判或记录为未决。

## 七、建模表达：把过程留在文件里

用 **PartDesign**（`Body ▸ Sketch ▸ Pad`）而不是直接给 `Part::Feature` 赋 Shape：

- 每个座台一个 `Body`，名字带列/位置（`座台_上_201_前`），草图可直接改高度重算；
- 侧壁整板 + 窗口也用 `Pad`/`Pocket` 表达，窗口位置随草图参数走；
- 交付时"看得见的建模过程"比"一个融合体的最终形状"更值钱——别人能改、能复核。

## 八、常见错误速查

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 侧壁出现"方块塔" | 竖壁 + 事后圆角 | 改成曲边梯形（腰＝座外圆） |
| 座台与座圆之间 1 mm 薄片 | 座台 Y/X 方向比壁面多伸 1 mm | 与壁面/座圆严格对齐，不要"多留一点" |
| 尖谷（最小宽度 1 mm 级） | 45° 斜面直接与座圆相交 | 加相切圆弧，或改用曲边梯形 |
| 剖视图露出两个洞 | 旧沉窝/旧孔未随新安装面重做 | 按第四节顺序重画，旧特征填实 |
| 端盖装不进 | 法兰 Y 向外伸过多盖住安装面 | 法兰 Y 向只到座面，别外伸 |
| 窗口边缘 4 mm 薄条 | 窗口只按"避让"定尺寸 | 至少留 8–12 mm 边，铣刀能进 |
